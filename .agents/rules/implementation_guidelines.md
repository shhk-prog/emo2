# v2 実装ガイドライン (v2 Implementation Guidelines)

本ガイドラインは **v2 (バージョン2) の実装・実験コード作成時** に適用される。
v2環境での実装作業を行う際は、本ファイルのルールを**必ず遵守**すること。

## 1. 必須参照ドキュメント
実装計画の策定や実装作業を行う際は、必ず以下のドキュメントを参照し、プロジェクトの目的・仮説・実験プロトコルを逸脱しないようにすること。
- `v2/docs/研究案.md`
- `AGENTS.md`

## 2. コード実装・ライブラリ利用のルール
- **カスタムコードの非推奨**: なるべく自前のカスタムコードやスクラッチからの実装を行わないこと。
- **公式コード・既存リソースの優先利用**: 実験の実行や分析処理には、公式のライブラリ・コード、および既にプロジェクト内に存在する既存スクリプトを優先して活用すること。

## 3. GPU実行に関するルール
- **GPUの無断実行禁止**: GPUを使用するコード（モデルの推論スクリプト、重い学習処理など）を、AIエージェントが自動的に（ユーザーの明示的な許可なく）ターミナルで勝手に実行してはならない。
- **実行コマンドの提示**: GPUを使用するスクリプトを実行する必要がある場合は、ターミナルで実行すべきコマンド（例: `python scripts/run_inference.py ...`）をテキストとして出力・提示し、ユーザーに実行を促す、あるいは実行の許可を求めること。

## 4. その他の遵守事項（AGENTS.md準拠）
- **仮想環境の利用**: コマンドの実行は必ずプロジェクト専用の仮想環境（例: `.venv`）内で行う。
- **原データの保護**: `data/raw/` などの原データは読み取り専用とし、絶対に上書きや変更を加えない。
- **結果の保護**: `results/raw/` などの実験結果は上書きせず、再実行時は別の `run_id` を用いる。
- **日本語での出力・ドキュメント作成**: チャット応答、および `docs/` に作成する `task.md`, `implementation_plan.md`, `walkthrough.md` は原則として日本語で作成する。
