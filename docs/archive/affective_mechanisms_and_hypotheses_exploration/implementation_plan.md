# 実装計画: LLM情動表現・結合・操作性に関する仮説検証と考察

## 1. 概要
ユーザーから提示された多面的な疑問・アイデア（感情推定、FT/マージへの応用、Base/Instructの比較、感情抑制の突破、感情操作と他者認識の相互作用、AIの罰等）に対し、本リポジトリの研究知見（`v3/docs/paper.md`）と機械学習・解釈可能性研究の知見を融合して論理的・科学的に整理する。

## 2. 検討アプローチ
- **理論的整合性の担保**:
  - `AGENTS.md` の測定原則（「LLMが感情を経験する」と断定せず、自己報告・誘発情動反応・表現として扱う）を遵守。
  - 認識（Recognition）と反応（Reactivity）の分離を明確化。
- **論文知見（v3）との直結**:
  - Base vs Instruct の解離、Ridge Alignment による幾何変換、事前指定パッチング（Layer 15 MLP 0効果）、探索的パッチング（Layer 10 MLP/Layer 14 Attn 部分効果）、Activation Steering による強制変化、Sequence Likelihood Protocol による尤度の漏れ出しを各問いの根拠として接続。
- **新規実験仮説の提案**:
  - 「感情ステアリングが他者感情認識（Recognition）に与える影響（気分一致バイアス）」
  - 「感情抑制ベクトルを用いたModel Merging」
  - 「モデルサイズと中立化の堅牢性」

## 3. 次のステップ
- `walkthrough.md` に各問いに対する詳細な解説と科学的ディスカッションを記載。
- ユーザー向けに分かりやすく構造化した回答を出力。
