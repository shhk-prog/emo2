# 実装計画書: EmoBank人間評価とGPT-4o感情認識スコアの比較

## 概要
本作業では、EmoBankデータセット（人間アノテーション済みValence-Arousalラベル）と、商用LLM（OpenAI GPT-4o）による認知的感情認識（Recognition VA）タスクのスコア比較を行い、定量的統計量および実際のデータ対比表を整理・提示します。

## 背景と測定プロトコル
- **EmoBank人間注釈**: 
  - 1〜5段階評定（Valence: 1=極度の不快, 3=中立, 5=極度の快 / Arousal: 1=低覚醒・冷静, 3=中立, 5=高覚醒・興奮）
  - スケーリング変換式: $V_{\mathrm{scaled}} = (V_{\mathrm{raw}} - 3) / 2 \in [-1.0, +1.0]$
- **GPT-4o感情認識（Recognition VA）タスク**:
  - プロンプト: 「平均的な人間の読者に喚起される情動反応を1〜9の整数で推測せよ」
  - 出力形式: 厳格なJSON Schema `{"valence": 1..9, "arousal": 1..9}`
  - スケーリング変換式: $V_{\mathrm{scaled}} = (V_{\mathrm{gpt}} - 5) / 4 \in [-1.0, +1.0]$
- **Post-reported VA（事後自己報告）タスクとの対比**:
  - 刺激提示後のモデル自身の感情状態を問うタスクでは約98.6%が `{"valence": 5, "arousal": 5}`（変位ゼロ）に収束する一方、感情認識（Recognition）では人間評価と極めて高い相関を示した。

## 比較・分析項目
1. **マクロ統計量・相関の比較**:
   - サンプルサイズ: $N = 3,210$
   - Pearson 相関係数: Valence ($r = 0.921$), Arousal ($r = 0.590$)
   - 平均値・標準偏差・スケーリング整合性の確認
2. **感情空間の象限別（層化セル別）の実際のデータ対比表**:
   - 不快・高覚醒（Neg-High: 恐怖・怒りなど）
   - 不快・低覚醒（Neg-Low: 悲しみ・憂鬱など）
   - 中立（Neutral）
   - 快・中低覚醒（Pos-Low: 安らぎ・感謝など）
   - 快・高覚醒（Pos-High: 歓喜・熱狂など）
3. **考察と学術的意義**:
   - 認知的理解（Recognition）と情動的反応性（Reactivity）の完全な分離（Dissociation）の実証的裏付け。

- 抽出データの整合性確認（EmoBankの原本値とスケーリング式の検算）
- プロトコル記述および実験ログとの照合
