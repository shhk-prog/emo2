# 実装計画: Phase B 考察セクションの書式整形（単語・意味の完全維持）

## 目的
`/mnt/nas/home/hiromi/src/emo/v3/docs/paper_v1.md` 内の `# phase Bの考察` セクションにおいて、文意や使用単語を一切変更せず、Markdownの見出し構造、数式ブロックのLaTeX構文エラー（`\\`の抜けや`[`表記の乱れ等）、細切れな空行や特殊記号を学術論文ドラフトとして美しく整える。

## 主な整形方針
1. **意味・語彙の厳格な維持**:
   - 既存のすべての単語、数値、論理、文章表現を一字一句変更しない。
2. **見出し構造のMarkdown階層化**:
   - `# phase Bの考察` を大見出しとし、`## 1. 総括...`, `### 2.1 Paraphrase...` のように論理的なMarkdown見出しに整理。
3. **LaTeX数式ブロックの構文修復**:
   - 単なる角括弧 `[` `]` で囲まれていたブロックを `$$ ... $$` やインライン `$ ... $` に正しく変換。
   - `\begin{aligned}` や `\begin{array}` における改行エスケープ漏れ（`\` → `\\`）を修復。
   - 崩れていた構文（`\text{Affective representation}` 関連の枠組み等）を正しく閉じられたLaTeX表記に整形。
4. **レイアウトと読みやすさの向上**:
   - 過剰な1行ごとの空行を論文段落として自然に整え、特殊文字 `⸻` を標準的なセクション区切り等に整理。
