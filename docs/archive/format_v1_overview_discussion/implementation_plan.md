# 実装計画: V1の概要考察の書式整形（意味・単語の完全維持）

## 目的
`/mnt/nas/home/hiromi/src/emo/v3/docs/paper_v1.md` 内の「V1の概要」セクション（Line 3219〜4710）について、**文章の意味や使用単語を一字一句変更せず**、以下の学術的MarkdownおよびLaTeX書式整形を行う。

## 方針
1. **意味・語彙・文構造の完全維持**:
   - ユーザーが記述したテキストの単語、数値、説明、論理展開を1文字たりとも改変しない。
2. **見出し構造の階層化**:
   - 重複している大見出しを `# V1の概要：実験フレームワークと実装プロトコル` に統合。
   - `1. 全体像...` 〜 `9. V1の最も安全な総括` を `##` 見出しへ。
   - `4.1 E1...` 等を `###`、`4.1.1 Hidden State...` 等を `####` 見出しへと論理的に階層化。
3. **LaTeX 数式の修復**:
   - 裸の括弧 `[` `]` で記述された数式ブロックを `$$ ... $$` やインライン `$ ... $` へ修正。
   - 中断・空白行や記号抜け（`\sum_c` の前の `=` など）を整え、正しくレンダリングできるLaTeX表記に整形。
   - インラインの変数表記 `(x)`, `(l)`, `(R^2)`, `(\alpha)` 等を `$x$`, `$l$`, `$R^2$`, `$\alpha$` に統一。
4. **レイアウトと読みやすさの改善**:
   - タブ文字で崩れているテーブル（各実験の問い、4条件の意味変換実験など）をMarkdownテーブルに整頓。
   - 箇条書きや細切れな空行を段落として自然にレイアウト。
