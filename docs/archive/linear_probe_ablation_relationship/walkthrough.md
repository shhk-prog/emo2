2. **v1草稿（`paper_draft.md`）末尾の記録（行283〜285）**:
   > `run_causal_intervention.py` によるQwen2.5-1.5B-Instructを用いた**全28層の因果介入パイロット実験**において、以下の詳細な効果が確認された。

## 3. v1における Linear Probe と Ablation の関係

v1の実験設計における両者の役割と関係性は以下の通りです。

```text
[入力刺激] ───> [Layer 4] ───> [Layer 12-14] ───> [Layer 14-25] ───> [Layer 27] ───> [出力自己報告]
                  ▲               ▲                 ▲
                  │               │                 │
             Ablation最大    Ablation中程度     Probe最大
             (低減 42.26%)   (低減 20〜30%)    (AUC > 97.5%)
```

| 比較項目 | Linear Probe (線形プロービング) | Ablation (除去・消去介入) |
|---|---|---|
| **学術的問い** | 「感情情報はモデルの内部に**保持されているか**？」<br>（H1: Erasure仮説の検証） | 「その層の表現は、自己報告の生成に**必要不可欠か**？」<br>（Necessity / Causal Roleの検証） |
| **評価手法** | 各層の隠れ状態から感情ラベルを線形分類（Ridge回帰・ROC-AUC） | 当該層の活性を「中立刺激の平均ベクトル」に置換し、尤度シフトの減少率を測定 |
| **最高効果の出現層** | **中間〜深層（Layer 14〜25）**<br>（ROC-AUC > 97.5%） | **浅層〜中間層（Layer 4, Layer 12–14）**<br>（Layer 4: 42.26%低減） |
| **導かれた結論** | RLHF後もモデル内部から感情情報は消去されていない（内的符号化の存在）。 | 単一の層を消去しても効果は最大42%しか消えず、感情処理は単一ボトルネックではなく複数層に分散している。 |

### なぜ両者を対比させることが重要なのか？
- **「情報が読める層」と「除去すると困る層」の乖離**:
  - もし中間層（Layer 14–25）だけでAblationを行っていた場合、Layer 4のような浅層での強い低減効果（42.26%）を見落とすことになります。
  - 逆に、プローブ精度が高い中間層（Layer 14–25）では、Ablationを行ってもモデル下流の並列計算や残差接続によって迂回されるため、消去効果が限定的になります。
- **結論**:
  Linear Probe（情報存在）とAblation（因果的必要性）は異なる側面を捉えているため、**「どちらも全28層プロファイルとして並べて対比する」**ことによって初めて、感情情報の伝播・迂回・分散処理の全貌を明らかにできます。
