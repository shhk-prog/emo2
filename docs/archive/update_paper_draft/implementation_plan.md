## 提案する変更内容

### 1. 予備実験の詳細設定と結果の拡充 (5.1章)
現在の5.1章の記述に加えて、以下の詳細を明記します。
- **データセット**: EmoBank（3,210刺激）を使用したこと。
- **認知的理解と情動的反応性の対比**: 感情認識（Recognition）では EmoBankの人間注釈値と強い正の相関（Valence $r = 0.921$、Arousal $r = 0.590$）を示したにもかかわらず、自己報告（Post VA）では 3,166回（約98.6%）が完全なニュートラルに収束したという「認識と反応の乖離」の詳細な記述。

### 2. 本実験（因果介入）の詳細設定と結果の拡充 (5.4章付近)
現在の5.4章（因果介入の結果）は数行しかないため、以下の詳細な仕組みと結果の表を追記します。
- **バッチ推論と抽出層**: Qwen2.5-1.5B-Instruct 等を用いた Left Padding バッチ推論アーキテクチャの導入。
- **Activation Patching の具体的な仕組みと表**: Source条件（ネガティブな刺激）の隠れ状態を抽出し、Target条件（ニュートラル・ベースライン）の推論途中にPyTorchのForward Hookで差し替える仕組みを具体的な表で提示します。
- **Recoveryスコアの解釈**: パイロット実験で観測された Recoveryスコア 83.3% が、単なる相関ではなく「出力の因果的な制御」を意味する強い証拠であることの詳細な解説。
