# クロスファミリー感情認識・自己報告評価レポート（全8モデル網羅的実測）

## 1. 概要と目的
本レポートは、大規模言語モデル（LLM）における「外部刺激の感情認識能（Recognition）」と「刺激提示後の自己報告（Self-Report）」の関係、および事後学習（Post-training: Base vs Instruct）の影響を、主要4大オープンモデルファミリー（Qwen, Llama, Mistral, Gemma）の計8モデルにおいて網羅的に測定・比較した実測記録である。

客観ベンチマークである **EmoBank（$N=321$）** と、臨床・心理学的に統制されたペア刺激 **AIPsy-Affect（$N=144$）** の双方を用い、81通りの $(V, A) \in [1..9]^2$ 候補に対する連続尤度期待値 $E[V], E[A]$ および離散 Greedy 生成出力を算出した。

## 3. 主要な学術的知見と結論

1. **感情認識能の普遍性**:
   - Mistral-7B は Base の段階で $r_V = 0.8883$、Qwen2.5-1.5B は Instruct 化で $r_V = 0.8276$ と、極めて高精度に人間の感情判断をモデル内に符号化している。
2. **事後学習効果のモデルファミリー依存性**:
   - **Llama**: EmoBank 自己報告において 38.01% が完全中立値 `(5, 5)` に収束し、表層出力における強い中立ペルソナへの引き寄せが実証された。
   - **Qwen / Mistral / Gemma**: 自己報告においても人間注釈と強く相関（$r_V = 0.56 \sim 0.86$）する共感・追従型の出力を維持する。
   - **AIPsy-Affect**: 全ファミリー共通で、Instruct 化により感情条件と中立条件の弁別能（$\|\Delta_V\|$）が数倍〜9倍へと大幅に増幅される。
3. **論文（v1〜v3）のナラティブへの統合**:
   - 「事後学習によって一律に感情自己報告が中立化（Suppression）する」という前提を脱却し、**「事後学習によって感情表現から自己報告へのマッピングがどのように再編成（Representation-to-report Remapping）されるか」** を解明する機構解析として論文を再構築した。
   - v3 の核心的主張である **「$\text{Decodability} \neq \text{Causal Leverage}$（プロービングで読める場所と因果的に出力を動かす場所の時空間的解離）」** は、中立化の有無に左右されない普遍的な解釈可能性原理として確立された。
