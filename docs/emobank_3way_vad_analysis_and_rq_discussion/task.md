# EmoBank 3-Way VAD 実験結果の学術的考察およびリサーチクエスチョン（RQ）の解明

## 目的
EmoBank テストセット（N=1,000）における 3-Way VAD 評価結果（① Writer推定、② Reader予測、③ Self自己報告、④ 内部結合度 Coupling）に基づき、以下の問いに対する包括的・学術的な考察を実施する。

1. **基本4タスクの推論性能**:
   - ① Writer：書き手の感情を理解できるか
   - ② Reader：人間がどう感じるか予測できるか
   - ③ Self：LLM自身はどう感じると報告するか
   - ④ Coupling：②で予測した人間の感情と③の自己報告はどの程度連動するか
2. **モデル特性の比較分析**:
   - 事前学習モデル（Base）と指示追従モデル（Instruct）の差異
   - モデルファミリー（Qwen, Mistral, Llama, Gemma）およびパラメータ規模による特性差
3. **5大リサーチクエスチョン（RQ1〜RQ5）への回答**:
   - RQ1: LLMは人間の情動状態（Writer/Reader）をどの程度正確に推論・予測できるか？（Alignment vs. Calibration）
   - RQ2: モデル自身の自己報告（Self）は人間の反応に対応しているか？（相関・系統的バイアス）
   - RQ3: 事前学習（Base）と事後学習（Instruct）で感情認識・自己報告・結合度はどう変化するか？
   - RQ4: モデルファミリーやパラメータ規模によって特性はどう異なるか？
   - RQ5: 他者認識（Reader）と自己報告（Self）はモデル内部でどの程度連動しているか？（認知的鏡像 Mirroring の検証）
