# Implementation Plan: 14の問いに対する文献ギャップ分析の計画

## 1. 整理方針
ユーザーが提示した14個のトピックに対して、以下の2軸で峻別を行う：
- **【すでにあるところ】（Established / Prior Work）**:
  - 論文名・研究領域（Representation Engineering, Mechanistic Interpretability, Alignment, Model Merging等）で既に手法や知見が確立しているもの。
- **【ないところ】（Open Gap / 本研究の新規性 / 未踏のフロンティア）**:
  - 先行研究では見落とされていたもの、本研究（`v3/docs/paper.md`）が初めて実証したもの、あるいは今後世界で初めて実証可能な新規実験アイデア。

## 2. 評価対象の14項目
1. 内部状態からの感情推定（Probing）
2. FTによる感情表出の激化
3. FTによる回路遮断・転移とModel Mergeへの応用
4. 感情同定の工学的・科学的動機
5. Base vs Instruct の差とパラドックス
6. 会話ロールプレイ能力と機能的自己報告の解離
7. 三人称認識（普通の人の感情）プロンプトでの表出
8. 感情回路のAblation（消去）によるニュートラルモデル
9. 極端な刺激による抑制の突き破り（Jailbreak）
10. 出力抑制下での尤度空間への漏れ出しメカニズム
11. LLMをキレさせること（対話文脈による感情蓄積）
12. 感情操作が他者感情認識に与える影響（気分一致バイアス）
13. モデルサイズ（小規模モデル）と抑制の脆弱性
14. AIにとっての「嫌なこと」「罰」の定義
