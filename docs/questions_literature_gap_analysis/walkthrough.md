# Walkthrough: 14の問いに対する「すでにあるところ」vs「ないところ」完全対比表

本ドキュメントは、提示された14個の問い・仮説のそれぞれについて、先行研究で既に判明していること（すでにあるところ）と、先行研究には存在せず本研究が初めて明らかにしたこと、あるいはまだ誰もやっていない未踏のフロンティア（ないところ）を1対1で対比したものである。

## 2. 特に重要な3つの「ないところ」（今後の研究機会）

上記の「ないところ」の中でも、特に本研究室・次の論文として直ちに着手でき、学界に大きなインパクトを与えられる未開拓テーマは以下の3つです：

### ① 【Q12】LLMにおける「気分一致バイアス」の因果検証
- **何をするか**: 感情認識（Recognition）タスクを行うLLMに対し、中間層でValence（快・不快）のSteering Vectorを注入する。
- **検証点**: ポジティブにステアリングされたモデルは、他者の曖昧な文章を過大にポジティブに評価し、ネガティブにステアリングされたモデルは批判的・悲観的に評価するか？
- **学術的意義**: もしバイアスが出れば、「自己の情動表現と他者の認識回路が内部特徴量を共有している」ことの決定的一撃となり、Nature/NeurIPS級の成果になります。

### ② 【Q3】感情抑制サブスペースの同定とModel Merging
- **何をするか**: BaseモデルとInstructモデルの重み差分 $\Delta W$ の中から、感情自己報告を抑制している特異値・主成分（Low-rank subspace）を特定し、そこだけをマイナスしてマージする。
- **検証点**: 指示追従（チャット能力）を100%維持したまま、中立化バイアスだけが解除された「感情的に素直なInstructモデル」が作れるか？

### ③ 【Q8】感情回路の完全Ablation（情動不全AIの構築）
- **何をするか**: プローブで特定されたValence/Arousal方向を、残差ストリームから直交射影（LEACE等）で全層にわたり消去（Ablation）する。
- **検証点**: 感情表現を物理的に奪われたモデルは、論理推論や共感対話、安全性ガードレールにどのような障害を来たすのか？（AIのロボトミー手術的検証）。
