# 実装計画: v2におけるBaseモデルとInstructモデルの感情自己報告メカニズム比較

## 1. 概要
本計画は、ユーザーから寄せられた「感情情報が内部にあるのに、なぜInstructモデルは自己報告に出さないのか」「Baseモデルでは出ることが示されているのか」という疑問に対し、v2研究成果に基づいて明確なエビデンスと理論的解釈を提示するための構成案である。

## 2. 検討項目と構成

### 2.1 疑問1: Baseモデルでは自己報告に感情情報（VAのシフト）が出ることが示されているのか？
- **結論**: はい、明確に出ることが示されている。
- **エビデンス**:
  1. **離散生成（Greedyデコーディング）**: Instructモデルでは83.3%〜98%以上が完全な中立値 `{"valence": 5, "arousal": 5}` や中立テンプレ文に虚脱（collapse）するのに対し、Baseモデルでは中立固定化が起きない。
  2. **尤度ベース期待値（Sequence Likelihood / Continuous Readout）**: 81通りの候補に対する期待値 $E[V], E[A]$ において、Baseモデルは刺激の感情価（Peak/Moderate/Neutral）に応じて有意に自己報告がシフトする（例: 怒り・恐怖で低Valence、歓喜で高Valence/高Arousal）。
  3. **分布の多様性**: Baseモデルの $(5,5)$ 確率 $p_{55}$ はわずか 0.8%〜2.4% に過ぎず、エントロピーが高く保たれ、感情に応じて分布全体が移動する。
  4. **内部と出力の相関**: 内部の感情表現強度と自己報告の間に強い結合（Coupling）が存在する。

### 2.2 疑問2: 内部に感情情報があるのに、なぜInstructモデルは自己報告に出さないのか？
- **検証された4つの仮説と棄却/支持の理由**:
  1. **H1 (Erasure: 感情情報消去説) $\to$ 棄却**:
     - Instructモデル内部にも線形プローブで高い精度（$R^2 > 0.318 \sim 0.58$、ROC-AUC > 97%）でValence/Arousal情報が保持されている。消去されたのではない。
  2. **H2 (Representation Transformation: 幾何的変容説) $\to$ 部分的支持**:
     - 事後学習（SFT/RLHF）により表現幾何が非直交的に歪められている。
  3. **H3 (Global Suppression / Single Output Gating: 単一ボトルネック・一様抑制説) $\to$ 棄却**:
     - 全層一様に結合が抑制されているわけではない（層によってはInstructの方がSlopeが大きい）。
     - 中間層の単一コンポーネントパッチング（Layer 20 MLPなど）ではBase型分布に戻らない。
     - 最終出力段（RMSNorm, lm_head）をスワップしても中立化は解除されず、出力直前の単一ゲートで切断されているわけではない。
  4. **H4 (Distributed Readout Remapping: 分散的再写像説 & ペルソナアライメント) $\to$ 最有力解釈**:
     - **アライメントによる「中立AIアシスタント」事前分布の支配**: 事後学習（SFT/RLHF）を通じて「AIは感情を持たない」「主観的自己報告は中立（5, 5）であるべき」という規範が強く埋め込まれた。
     - **システム乖離（System Dissociation）**: 文脈理解のために内部では感情情報を計算・保持するが、自己報告への出力写像（Coupling function）は複数の中間層〜深層（Layer 10 MLP, Layer 14 Attention等）に分散して「中立へ収束させる」ように再配線（Remapping）されている。
     - **ステアリングによる実証**: 内部の感情方向に直接活性化ステアリングを加えると自己報告が強制的に中立から脱却することから、物理的な切断ではなく、入力から出力への伝播プロセスが中立アトラクター（Sink）に引き込まれる構造になっている。
