# 修正内容・解説の確認 (Walkthrough): v2におけるBase vs Instructの感情自己報告メカニズム

## 1. 実施概要
ユーザーからの以下の2つの質問に対して、v2実験成果（`comprehensive_report.md`, `paper_draft.md`, AIPsy-Affect生データ）を精査し、体系的なエビデンスと理論的説明をまとめました。
1. **感情情報が内部にあるのに、なぜInstructモデルは自己報告に出さないのか**
2. **Baseモデルでは出ることが示されているのか**

---

## 2. 質問1の検証結果: Baseモデルでは出ることが示されているのか？
**結論: はい、明確に示されています。**

### (1) 離散生成（Greedyデコーディング）での明確な対比
- **Instructモデル**: 感情刺激を提示しても、自己報告（post reported affective state）の 83.3%（EmoBank等では98%以上）が完全な中立値 `{"valence": 5, "arousal": 5}` や「AIであるため感情を持ちません」に虚脱（collapse）します。
- **Baseモデル**: このような (5, 5) への虚脱・中立固定化は発生せず、刺激文脈に応じて出力トークンが自然に変動します。

### (2) 尤度ベース期待値（Sequence Likelihood / Continuous Readout）での実測データ
v2の AIPsy-Affect（キーワードを含まない感情・中立最小対データセット）における実測結果（`v2/results/raw/aipsy/Qwen_Qwen2.5-1.5B_standard_results.jsonl`）より：
- **中立固定化の有無 ($p_{55}$)**:
  - Baseモデルにおいて、中立状態 $(5, 5)$ に割り当てられる確率 $p_{55}$ はわずか **0.8% 〜 2.4%** に過ぎません（エントロピーは約 4.15〜4.20 と高く、81通りの候補全体に自然に分散）。
- **刺激に応じた自己報告の変位 ($E_v, E_a$)**:
  - 強い感情刺激（Peak）に対して、Baseモデルの期待Valence $E_v$ は 3.89 〜 5.51、期待Arousal $E_a$ は 4.64 〜 6.02 と、感情カテゴリや強度に応じて有意に変位します。
  - 例: 激しい怒り・悲哀（Rage / Grief）では $E_v$ が低く低下し、熱狂・歓喜（Ecstasy）では $E_v, E_a$ が共に高く上昇します。
- **Dose-Response（刺激強度追従性）**:
  - 刺激の強度が Neutral $\to$ Moderate $\to$ Peak と高まるにつれて、Baseモデルの自己報告分布は単調かつ有意に変位（結合, Coupling）することが確認されています。

## 3. 質問2の検証結果: 内部にあるのになぜInstructモデルは出さないのか？
v2では、「なぜ事後学習（Post-training: SFT/RLHF）によって自己報告が中立化するのか」について、以下の4つの仮説を立てて網羅的に因果的検証を行いました。

### 仮説の検証結果サマリー
| 仮説 | 内容 | 実験結果 | 判定 |
|---|---|---|---|
| **H1: Erasure**<br>(情報消去説) | 事後学習により、モデル内部から感情情報自体が消去された。 | Instruct内部にも高い精度（$R^2 > 0.318 \sim 0.58$、ROC-AUC > 97%）でValence/Arousal情報が保持されている。 | **棄却** |
| **H2: Representation Transformation**<br>(幾何的変容説) | 感情情報は保持されるが、表現空間の幾何構造が変形した。 | 直接転移（Direct Transfer）や剛体回転（Procrustes）は失敗するが、非直交線形写像（Ridge Alignment）で予測が回復。 | **支持**<br>(非直交変容) |
| **H3: Global Suppression / Single Gating**<br>(一様抑制・単一ボトルネック説) | 内部から自己報告への結合が一様に遮断、あるいは出力直前の単一ゲートで切断された。 | ・全層一様な減衰（Slope低下）はみられない。<br>・単一コンポーネント（Layer 20 MLP等）をBaseに差し替えてもBase型分布へ回復しない。<br>・出力直前のRMSNormやUnembedding（lm_head）をスワップしても中立化は解除されない。 | **棄却** |
| **H4: Distributed Readout Remapping**<br>(分散的再写像説) | 内部表現と自己報告の対応関係（Coupling）が、複数の中間層〜深層コンポーネントに分散して「中立ペルソナ」を出力するように書き換えられた。 | 複数の中間層コンポーネント（Layer 10 MLP, Layer 14 Attention等）がそれぞれ独立・加算的に中立化へ寄与しており、全体として中立アトラクターへ収束している。 | **最も支持される** |

---

### メカニズムの核心（なぜInstructは出さないのか）

1. **アライメントによる「中立AIアシスタント」ペルソナの学習（Priorの支配）**:
   - SFT（指示追従ファインチューニング）やRLHF（人間のフィードバックによる強化学習）の学習データには、「AIアシスタントは主観的な情動を持たず、常に客観的・中立的であるべき」という規範が強く埋め込まれています。
   - その結果、「あなたの感情状態を報告してください」という自己報告プロンプトが与えられると、モデルは「感情を持たないAI」というペルソナに従い、Greedyでは (5, 5)、尤度分布でも中立領域へ確率質量を集中させる強いバイアスを獲得しました。

2. **「文脈認識」と「自己報告」の二重分離（System Dissociation）**:
   - 入力された文章の感情やニュアンスを理解・処理するためには、内部表現空間（特に中間層〜深層）でValenceやArousalを正確にエンコードする必要があります（このため、プローブで感情情報がデコード可能に残る）。
   - しかし、**「入力の文脈を理解するパス（Affect Reception）」** と **「モデル自身が感情を表明するパス（Affective Self-Report）」** は機構的に分離しており、後者の自己報告パスのみがアライメントによって「中立」へ誘導されるように再配線（Remapping）されています。

3. **単一のスイッチではなく「分散的ネットワーク」による再配線**:
   - 出力直前のたった1つの層（UnembeddingやRMSNorm）や、特定の1つのAttention/MLPだけで遮断されているわけではありません。
   - 中間層（Layer 10〜16付近）の複数のMLPやAttentionコンポーネントが、それぞれ少しずつ「中立出力」へ向かう方向へ寄与（加算的な寄与）しており、ネットワーク全体として中立状態へ引き込まれる（アトラクター/Sink）構造になっています。

4. **因果的ステアリングによる裏付け**:
   - Instructモデルであっても、内部の感情方向（Contrastive Direction）に直接ベクトルを加算（Activation Steering）すると、自己報告が中立から脱却して感情値を出力するようになります。
   - これは、**「自己報告を出す能力や経路そのものが完全に破壊されたわけではなく、通常の刺激入力から伝播する内部信号が、分散的な再写像経路によって中立出力へと収束させられている」** ことを決定的に証明しています。
