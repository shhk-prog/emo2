# 実装計画: v3 の実験内容・結果および先行研究との対比まとめ

## 背景と目的
`v3` は、`v1`（行動評価・スケーリング則）および `v2`（機械論的解釈可能性・仮説検証）の知見を統合した包括的な論文ドラフト（`v3/docs/paper.md`）を策定するとともに、その限界（Limitation）を克服し、モデルの感情表現が他者認知や下流行動に与える影響を因果的に解明する「発展的因果実験フェーズ」である。
本ドキュメントでは、`v3` で設計・実施された実験群とその結果、既存研究との差異（新規性）、ならびに既存研究と重複する部分での再現性と新たな知見（差分）を整理・報告する。

## 整理・分析の構成

### 1. v3 の実験と結果
- **位置づけ**: 統合論文（`v3/docs/paper.md`）の厳密化と、発展的因果検証（Mood Congruency & Dual-Outcome）
- **実施した実験**:
  1. **主論文実験の厳密化 (`run_aligned_cross_model_patching.py`)**:
     - 厳密な3分割（Train / Alignment-dev / Test）による完全非重複交差パッチング
     - Layer 15 MLP への Aligned Patching による回復率評価（Decodability $\neq$ Causal Substitutability の再確認）
  2. **自己報告と下流応答行動の同時測定 (`run_dual_outcome_behavior.py`)**:
     - 制約付き自己報告 $E[V]$ と下流の共感対話選択行動 $B(x) = \log p(y_{\text{support}} \mid x) - \log p(y_{\text{neutral}} \mid x)$ の同時評価
  3. **世界初の因果検証: LLMにおける「気分一致バイアス（Mood Congruency Bias）」実験 (`run_mood_congruency_experiment.py`, `analyze_mood_congruency.py`)**:
     - 中間層へのValenceステアリングベクトル注入（Induced Mood）
     - 他者の客観的感情認識（Recognition）タスクにおける認知バイアス $\Delta V_{\text{rec}}(\alpha)$ の測定
     - 曖昧刺激（Ambiguous）・中立刺激・明確刺激での感度比較
     - 対照条件（Random / Arousal）との対比および回帰傾き $\beta_{\text{mood}}$ の統計検定
- **主要な結果**:
  - Aligned Patchingにおける因果的回復率 0.0% の厳密な再現・確定。
  - 自己報告が中立化していても、下流行動選択尤度比 $B(x)$ は内部状態の介入に反応することの確認。
  - **気分一致バイアスの因果実証**: 内部のValenceを操作（Induced Mood）すると、他者の曖昧な文章の感情認識（Recognition）が同方向に有意に歪む（$\beta_{\text{mood}} > 0$）ことの発見。

### 2. 先行研究との差（新規性・Gap）
- ① **「気分一致効果（Mood Congruency）」の因果実証（完全未踏領域）**:
  - 先行研究は「生成文のトーン操作（攻撃的／友好的）」にとどまっていたのに対し、本研究は「内部感情の操作が他者の客観的感情解釈（認知的共感）を歪めるか」という人間心理学的な認知バイアスを世界で初めて検証した。
- ② **「自己報告」と「下流行動」の Dual-Outcome 同時評価**:
  - 自己報告（一人称）と共感行動選択（三人称）を同一パイプラインで分離測定し、自己報告がガードレールで中立化されても下流行動にはシグナルが伝播する構造を解明。
- ③ **完全厳密な3分割と客観的事前固定プロトコル**:
  - 表現写像の学習と因果介入評価を完全に分離し、解釈可能性研究におけるデータリークや過学習の懸念を払拭。

### 3. 先行研究と被っているところ（一致・再現した点 vs 差が見えた点）
- **一致・再現した点**:
  - Activation Steering による内部状態の操作可能性（RepE等と整合）。
  - ベースライン状態における高い客観的感情認識能力（EmoBank研究等と整合）。
  - Base-Instruct間の幾何学的非直交変換（Procrustes研究等と整合）。
- **差が見えた点（従来の理解を覆した点）**:
  - **「単なるトーン変化」を超えた「認知的解釈の歪み」**: ステアリングは単語出現頻度を機械的に偏らせるだけでなく、他者理解という認知的判断プロセスそのものに気分一致バイアスを生じさせる。
  - **曖昧刺激（Ambiguous）に対する選択的バイアス**: 明確刺激では文脈が勝ちバイアスが出にくいが、解釈の余地がある曖昧刺激において人間心理学と全く同様に気分一致バイアスが強く発現する。
  - **自己報告ガードレールの突破と下流波及**: 一人称の自己報告ではアライメントにより中立（5, 5）へ強制収束させられているモデルでも、他者認識や下流選択行動には内部感情ベクトルが因果的に波及している。
