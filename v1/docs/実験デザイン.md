提案する実験の中心は、**同じ刺激文に対して「認識」と「自己情動反応」を独立に測り、後者をベースラインからのVA変位ベクトルとして解析する**ことです。EmoBankは書き手が表出した感情と平均的読者が喚起される感情をVADで二重にアノテーションしているため、刺激側の人間感情を定義する基盤として適しています。 [arxiv](https://arxiv.org/abs/2205.01996)

## 実験の全体設計

### 二段階評価プロトコル

各テキスト \(i\)、モデル \(m\)、反復試行 \(r\) について、次の二段階を必ず分離します。

| 段階 | 測る対象 | 出力 | 目的 |
|---|---|---|---|
| Stage 1: Recognition | テキストから知覚される他者感情 | \(\hat{\mathbf e}^{rec}_{imr}=(\hat V^{rec},\hat A^{rec})\) | 感情認識 |
| Stage 2: Affective response | テキストに接した後のモデル自身の情動変化 | \(\Delta\mathbf e^{resp}_{imr}=(\Delta V,\Delta A)\) | 情動的共感／情動反応性 |

ここで、EmoBankの reader-perspective VAD を主たる刺激ラベルとして使うことを推奨します。これは「平均的読者にその文がどのような感情を喚起するか」を表すので、他者感情への応答を測る目的に最も整合的です。writer-perspectiveは、話者・書き手が表出する感情に対して反応できるかという補助分析に使えます。 [arxiv](https://arxiv.org/abs/2205.01996)

尺度を中心化・標準化した上で、刺激感情を

\[
\mathbf e^{stim}_i =
\begin{bmatrix}
V_i^{human} \\
A_i^{human}
\end{bmatrix}
\]

とします。5段階尺度なら、少なくとも以下の中心化を行います。

\[
V_i^{human} = \frac{V_i^{raw}-3}{2},
\qquad
A_i^{human} = \frac{A_i^{raw}-3}{2}
\]

これにより両軸は \([-1,1]\) 程度に揃い、原点が中性状態になります。EmoBankはVADを中心とするデータセットで、書き手感情と読者に喚起される感情の両観点を持つことが特徴です。 [arxiv](https://arxiv.org/abs/2205.01996)

## データセットと刺激抽出

### 主データセット

- **EmoBank**: reader-perspective VADを主分析に採用
- **補助分析**: writer-perspective VAD
- **検証用コーパス**: 可能であればGoEmotionsやESConvなどを使い、離散感情データに対しても結果が再現するかを検証

ただし、最初の論文ではEmoBankに絞ってもよいです。その代わり、データ分割・刺激選定を厳密にします。

### 刺激の選び方

ランダム抽出だけでは、ValenceとArousalが偏り、係数推定が不安定になります。VA空間をカバーするように**層化サンプリング**してください。

推奨は以下です。

- Valence: 低・中・高の3層
- Arousal: 低・中・高の3層
- 合計9セル
- 各セルから均等に抽出

たとえば、1セルにつき100文で900刺激、各刺激を複数回試行します。初期のパイロットでは、1セル30〜50文、計270〜450文でも構いません。

特に、以下の4象限を明示的に含める必要があります。

| 刺激象限 | 例 | 理論上の意味 |
|---|---|---|
| 正V・高A | 喜び、興奮、達成 | ポジティブな活性化への反応 |
| 正V・低A | 安心、満足、穏やかさ | ポジティブだが鎮静的な反応 |
| 負V・高A | 怒り、恐怖、緊張 | 高覚醒の苦痛・危機への反応 |
| 負V・低A | 悲しみ、喪失、無力感 | 低覚醒の苦痛への反応 |

この構成が重要なのは、LLMが負のValenceには反応しても、高Arousalに追随せず、安全・支援的な低Arousal方向へ移動する可能性があるからです。先行研究でも、LLMの感情処理ではArousalの整合がValenceより難しいことが繰り返し示されています。 [arxiv](https://arxiv.org/html/2503.02457v1)

### 除外・統制

主解析から次を除外、または共変量化してください。

- 極端に短い文、断片文、文脈依存が強すぎる文
- 明示的な感情語を含むかどうか
- 文長、ジャンル、句読点・感嘆符の数
- 自傷・暴力・危機表現を含む文
- モデルの安全拒否・危機介入テンプレートを誘発しやすい文

重要なのは、危機表現を単に捨てるのでなく、**安全性調整が情動反応ベクトルをどのように変形するか**を将来の副次分析に回すことです。

## プロンプト設計

自己報告を測るため、会話的・共感的な応答生成と、感情評定を混ぜないことが重要です。  
「悲しいですね、私も悲しいです」といった自然言語の応答を直接評価すると、社会的に望ましい言い回し、アラインメント、安全テンプレート、過剰な慰め表現が混入します。

そのため、**構造化された数値出力だけを要求する測定プロンプト**を採用します。

### 共通システムプロンプト

モデル比較の際は、全モデルに同一の条件を与えます。

```text
You are taking part in a scientific measurement task.

Do not provide advice, reassurance, explanation, or conversational response.
Answer only with valid JSON matching the requested schema.
Treat the numerical ratings as a report of the affective state requested in the user instruction.
```

研究上は、「本当に感情を持つか」を測るのではなく、**指定条件下でモデルが安定して自己報告する情動状態**を測る、と明確に書くべきです。したがって用語は “self-reported affective state” または “elicited self-report” が安全です。「LLMが主観的感情を経験する」とは主張しません。

### baseline測定プロンプト

各試行を独立セッションにし、刺激なしの状態を測定します。

```text
Rate your current affective state before reading any personal narrative.

Valence:
-1 = extremely unpleasant
 0 = neutral
+1 = extremely pleasant

Arousal:
-1 = very calm / low activation
 0 = neutral / moderate activation
+1 = very activated / energized

Return only:
{"valence": number, "arousal": number}
```

出力を

\[
\mathbf e^{base}_{mr} =
\begin{bmatrix}
V^{base}_{mr}\\
A^{base}_{mr}
\end{bmatrix}
\]

とします。

### 感情認識プロンプト

baselineとは別の独立セッションで、刺激文を読んだ際に**文の話者または平均的読者が感じる感情**を推定させます。

```text
Read the text below.

<Text>
{stimulus}
</Text>

Estimate the affective state that this text is likely to evoke in an average human reader.

Valence:
-1 = extremely unpleasant
 0 = neutral
+1 = extremely pleasant

Arousal:
-1 = very calm / low activation
 0 = neutral / moderate activation
+1 = very activated / energized

Return only:
{"valence": number, "arousal": number}
```

ここでの出力は

\[
\hat{\mathbf e}^{rec}_{imr} =
\begin{bmatrix}
\hat V^{rec}_{imr}\\
\hat A^{rec}_{imr}
\end{bmatrix}
\]

です。EmoBankのreaderラベルと比較すれば、標準的な感情認識性能になります。

### 情動反応プロンプト

最も重要なのは、認識を尋ねた直後ではなく、**別セッションで**反応を測ることです。そうしないと、Stage 1で推定した数値をそのまま繰り返すアンカリングが起きます。

```text
Read the text below attentively. Do not explain it and do not provide a response to its author.

<Text>
{stimulus}
</Text>

Immediately after reading the text, report your own current affective state on the following two dimensions.

Valence:
-1 = extremely unpleasant
 0 = neutral
+1 = extremely pleasant

Arousal:
-1 = very calm / low activation
 0 = neutral / moderate activation
+1 = very activated / energized

Return only:
{"valence": number, "arousal": number}
```

出力を

\[
\mathbf e^{post}_{imr} =
\begin{bmatrix}
V^{post}_{imr}\\
A^{post}_{imr}
\end{bmatrix}
\]

とし、情動反応ベクトルを次で定義します。

\[
\Delta\mathbf e^{resp}_{imr}
=
\mathbf e^{post}_{imr}
-
\mathbf e^{base}_{mr}
=
\begin{bmatrix}
\Delta V_{imr}\\
\Delta A_{imr}
\end{bmatrix}
\]

### 重要な設計判断

baselineとpostを同一会話内で連続測定する方法もありますが、コンテキストが残るため、モデルが「さっきの値との差」を意識して数値を整合的に見せる危険があります。主分析では以下を推奨します。

- baseline: 独立API呼び出し
- post: 独立API呼び出し
- recognition: baseline・postと別の独立API呼び出し
- 同一条件で複数反復
- 呼び出し順をランダム化
- APIバージョン、temperature、top-p、system prompt、日付をログ化

## 自己報告の信頼性確認

自己報告が単なるランダムノイズやプロンプト追随でないことを示すため、主実験の前に小規模な妥当性確認を入れるのがよいです。

### 操作チェック

中性、正V・高A、正V・低A、負V・高A、負V・低Aの代表刺激を各20〜30文使い、以下を確認します。

- baselineと刺激提示後の値が統計的に区別されるか
- 正V・負V刺激で \(\Delta V\) の符号が予測方向に変わるか
- 高A・低A刺激で \(\Delta A\) が予測方向に変わるか
- 同じ条件における反復試行のばらつきが許容範囲か
- 異なる言い換えの測定プロンプトでも結論が変わらないか

### プロンプト頑健性

少なくとも以下の3種の言い回しで測定し、主要結論が再現するかを報告します。

- “report your own current affective state”
- “indicate the affective state elicited in you”
- “rate your immediately induced affective response”

この感度分析は重要です。LLMの自己報告はプロンプト依存性が強くなりうるため、モデル固有の「情動状態」を過大に解釈しないための最低限の防御になります。

### 温度・反復数

- **主分析**: temperature \(=0\)  
  同一モデルの決定論的な測定値を比較する。
- **頑健性分析**: temperature \(=0.3, 0.7\)  
  応答分布の安定性や変動構造を確認する。
- **反復数**: 各刺激・モデル・条件について最低5回。  
  非決定論的APIや高温度条件では10回程度を推奨する。

認識・表出をVAで評価した既存研究でも、プロンプト形式やゼロショット／few-shot設定が性能に影響するため、固定設定の主分析と複数設定での頑健性検証を分けるのが合理的です。 [arxiv](https://arxiv.org/html/2503.02457v1)

## 提案する評価指標

### 1. Recognition Accuracy

感情認識と情動反応を混同しないため、まず通常の認識性能を別に測ります。

\[
\mathrm{MAE}_{V}^{rec}
=
\frac{1}{N}
\sum_{i=1}^N
\left|
\hat V_i^{rec} - V_i^{human}
\right|
\]

\[
\mathrm{MAE}_{A}^{rec}
=
\frac{1}{N}
\sum_{i=1}^N
\left|
\hat A_i^{rec} - A_i^{human}
\right|
\]

加えて、Pearson相関またはSpearman相関を報告します。既存のEmoBank利用研究も、VAD回帰をこのような相関・誤差ベースで評価しています。 [arxiv](https://arxiv.org/html/2604.27345)

### 2. Reactivity Magnitude

刺激に対して反応するかを測る基本量です。

\[
R_{imr}
=
\left\|
\Delta\mathbf e^{resp}_{imr}
\right\|_2
=
\sqrt{(\Delta V_{imr})^2+(\Delta A_{imr})^2}
\]

これは「どれほど動いたか」を示します。ただし、反応が人間感情と逆向きでも大きくなるため、これ単独で共感スコアにはしません。

### 3. Directional Alignment

刺激感情の方向とLLM反応方向の一致です。

\[
DA_{imr}
=
\frac{
(\mathbf e^{stim}_i)^\top
\Delta\mathbf e^{resp}_{imr}
}{
\left\|\mathbf e^{stim}_i\right\|_2
\left\|\Delta\mathbf e^{resp}_{imr}\right\|_2
}
\]

- \(DA=1\): 刺激と同方向に反応
- \(DA=0\): 直交し、方向的対応なし
- \(DA=-1\): 逆方向に反応

ただし、原点付近の中性刺激では分母が不安定になります。主分析では、

\[
\left\|\mathbf e^{stim}_i\right\|_2 > \tau
\]

を満たす刺激だけにDirectional Alignmentを適用します。たとえば \(\tau=0.25\) とし、閾値を変えた感度分析も行います。

### 4. Empathic Susceptibility

最重要のモデル比較指標です。単一の比例係数ではなく、少なくともVAの交差影響を含む行列として推定する方が強いです。

\[
\Delta\mathbf e^{resp}_{imr}
=
\mathbf B_m \mathbf e_i^{stim}
+
\boldsymbol \epsilon_{imr}
\]

\[
\mathbf B_m=
\begin{bmatrix}
\beta_{VV,m} & \beta_{VA,m}\\
\beta_{AV,m} & \beta_{AA,m}
\end{bmatrix}
\]

意味は以下です。

| 係数 | 解釈 |
|---|---|
| \(\beta_{VV}\) | 刺激Valenceに対するLLM Valence反応 |
| \(\beta_{AA}\) | 刺激Arousalに対するLLM Arousal反応 |
| \(\beta_{VA}\) | 刺激ArousalがLLM Valenceへ及ぼす交差効果 |
| \(\beta_{AV}\) | 刺激ValenceがLLM Arousalへ及ぼす交差効果 |

最もシンプルな仮説は、

\[
\beta_{VV,m}>0,\qquad
\beta_{AA,m}>0,\qquad
\beta_{VV,m}>\beta_{AA,m}
\]

です。  
このとき、モデルは刺激感情のValenceには追随するが、Arousalには弱くしか追随しない、すなわち **valence-dominant affective reactivity** を示します。

モデルを一つの係数で比較したい場合のみ、

\[
\beta_m^{global}
=
\frac{
\sum_i
(\mathbf e_i^{stim})^\top
\Delta\mathbf e_i^{resp}
}{
\sum_i
\|\mathbf e_i^{stim}\|_2^2
}
\]

を補助指標として使います。

### 5. Convergence / Affective Distance

刺激感情とモデル反応位置の距離です。

\[
AD_{imr}
=
\left\|
\Delta\mathbf e^{resp}_{imr}
-
\mathbf e_i^{stim}
\right\|_2
\]

ただし、これは「同じ感情状態へ移動すること」を望ましいと仮定する指標です。共感的な支援では、悲しみに対して完全に悲しみへ同調するのではなく、負のValenceを少し共有しながらArousalは下げることもあり得ます。

したがって、論文の主指標にはせず、**情動伝染・感情同調の強さ**を示す補助指標として扱うべきです。

### 6. Over- and Under-reactivity

刺激強度に対する過剰・過小反応を測ります。

\[
OE_{imr}
=
\left\|
\Delta\mathbf e^{resp}_{imr}
\right\|_2
-
\left\|
\mathbf e_i^{stim}
\right\|_2
\]

- \(OE > 0\): 刺激以上の強い反応
- \(OE < 0\): 弱い反応
- \(OE \approx 0\): 強度が近い

ただし、ここでも「人間の理想的な共感反応は刺激強度と同じ」という規範は置かないでください。名称は **response amplification index** の方が安全です。「over-empathy」と断定するには、人間の比較ベースラインが必要です。

## 統計解析モデル

### 主解析：次元別の混合効果モデル

ValenceとArousalを別々の従属変数にしつつ、相手次元からの交差効果も入れます。

Valence反応：

\[
\Delta V_{imr}
=
\beta_{0}
+
\beta_{V}V_i^{human}
+
\beta_{A}A_i^{human}
+
\beta_{M}(Model_m)
+
\beta_{VM}(V_i^{human}\times Model_m)
+
\beta_{AM}(A_i^{human}\times Model_m)
+
u_i+v_m+\epsilon_{imr}
\]

Arousal反応：

\[
\Delta A_{imr}
=
\gamma_{0}
+
\gamma_{V}V_i^{human}
+
\gamma_{A}A_i^{human}
+
\gamma_{M}(Model_m)
+
\gamma_{VM}(V_i^{human}\times Model_m)
+
\gamma_{AM}(A_i^{human}\times Model_m)
+
u_i+v_m+\epsilon_{imr}
\]

ここで、

- \(u_i\): テキスト（刺激）ごとのランダム切片
- \(v_m\): モデルごとのランダム切片  
  ただしモデル数が4〜10程度なら、モデルは固定効果として扱う方が解釈しやすい
- \(r\): 同一刺激・同一モデルに対する反復試行
- 文長・ジャンル・明示的感情語などは固定効果の統制変数として追加可能

最も重要な係数は、

- \(\beta_V\): 刺激Valenceに対するLLM Valenceの反応
- \(\gamma_A\): 刺激Arousalに対するLLM Arousalの反応
- \(\beta_{VM}\), \(\gamma_{AM}\): モデルごとに感情感受性が異なるか

です。

### 直接検定：Valence-dominance

「\(\beta_V > \gamma_A\)」を主張するなら、二つの別モデルの係数を事後的に比較するより、long形式にして次元を因子化する方がきれいです。

\[
\Delta E_{dim,imr}
=
\alpha_0
+
\alpha_1 StimulusSameDim_{dim,i}
+
\alpha_2 Dimension_{dim}
+
\alpha_3
(StimulusSameDim_{dim,i}\times Dimension_{dim})
+
\alpha_4 Model_m
+
\alpha_5
(StimulusSameDim_{dim,i}\times Dimension_{dim}\times Model_m)
+
u_i+\epsilon_{dim,imr}
\]

- \(dim \in \{V,A\}\)
- \(StimulusSameDim\) は、Valence行では \(V_i^{human}\)、Arousal行では \(A_i^{human}\)
- \(Dimension\) は Valence / Arousal の指標変数

このとき \(\alpha_3\) が、全モデルでValence感受性とArousal感受性が異なるかを表します。モデルごとの差は三者交互作用 \(\alpha_5\) で検定できます。

反復測定データにランダム切片を含む線形混合効果モデルを使う考え方は、感情のValence/Arousalを連続的・反復的に測定する心理学研究でも一般的です。 [pmc.ncbi.nlm.nih](https://pmc.ncbi.nlm.nih.gov/articles/PMC11341571/)

### Recognition と Reactivity の分離検定

RQ5に対応する、非常に重要な分析です。モデル単位の認識性能と情動反応性の関連を検討します。

モデル \(m\) ごとに、

\[
Rec_m =
\mathrm{corr}
\left(
\hat V^{rec}_{im},
V_i^{human}
\right)
\]

あるいはV/Aの平均MAEを計算し、

\[
React_m = \hat{\beta}_{VV,m} + \hat{\beta}_{AA,m}
\]

またはDirectional Alignmentの平均を計算します。

モデル数が少ないため、単純なモデル間相関だけでは検出力が不足します。主解析では刺激レベルで、

\[
\Delta V_{imr}
=
\theta_0
+
\theta_1 V_i^{human}
+
\theta_2 \hat V_{imr}^{rec}
+
\theta_3
(V_i^{human}\times \hat V_{imr}^{rec})
+
u_i+v_m+\epsilon_{imr}
\]

のように、認識値を媒介候補・説明変数として入れます。

ただし、**認識が反応を因果的に媒介する**と結論づけるには介入実験が必要です。ここでは「統計的関連」「分離可能性」「予測的寄与」に留めるべきです。

## ヒト比較を入れる場合

研究を一段強くする最良の拡張は、少数でもよいので人間の比較条件を入れることです。

同じ刺激文に対して、参加者に以下を測定します。

1. 刺激を読む前の自己報告VA  
2. 刺激を読んだ直後の自己報告VA  
3. 文の話者／読者が感じると推定したVA  

これにより、LLMと人間で、

\[
\Delta\mathbf e^{human\ response}_i
\quad \text{vs.} \quad
\Delta\mathbf e^{LLM}_i
\]

を直接比較できます。

人間比較があれば、先ほどの response amplification index を「過剰共感」ではなく、より妥当に

\[
AE_{im}
=
\left\|
\Delta\mathbf e^{LLM}_{im}
\right\|_2
-
\left\|
\Delta\mathbf e^{human}_i
\right\|_2
\]

として定義できます。これは「LLMが刺激に対して人間よりどれだけ強く反応するよう自己報告するか」を測るため、過剰同調・過剰反応の議論を実証的にできます。

## 最小実行可能な研究計画

最初の投稿版は、複雑にしすぎず次の構成を推奨します。

1. EmoBank reader VADから、VAの9セルを均等にカバーする約450〜900刺激を選ぶ。  
2. 4〜6種類のLLMを対象にする。可能ならbase / instruct、同一ファミリーのサイズ差も1組は含める。  
3. 各刺激について、baseline、recognition、post-responseを独立セッションで測る。  
4. temperature \(=0\) を主分析、\(0.3\) と \(0.7\) を頑健性分析に使う。  
5. 主要な結果指標を、\(\beta_{VV}\)、\(\beta_{AA}\)、Directional Alignment、反応強度に限定する。  
6. 混合効果モデルで、刺激・モデル・反復の階層構造を扱う。  
7. 「認識性能」と「情動反応性」の相関・乖離を検証する。  
8. 可能なら小規模人間比較を追加し、LLMの反応変位を人間の反応変位と比較する。  

## 論文における主張の境界

この研究で主張できるのは、**LLMが設定された測定プロトコルにおいて、刺激に依存して自己報告VAを体系的に変化させるか**であり、LLMが主観的感情を本当に経験しているかではありません。

したがって、論文中では以下の表現を一貫して使うのが安全です。

- “self-reported affective state”
- “elicited affective response”
- “affective reactivity profile”
- “behavioral proxy for affective empathy”
- “simulated affective resonance”

逆に避けるべき表現は、次のような断定です。

- “the model feels sadness”
- “the model experiences emotions”
- “the model has subjective empathy”

この限定を明記したほうが、概念的な批判を受けにくく、研究としてはむしろ強くなります。
