本研究は、**「共感的に見える応答」を測る予備実験**と、**その応答を支える機能的な内部状態変化があるかを検証する本実験**を分離する二段階設計にするのが最も強いです。重要なのは、主張を「LLMが主観的に感じている」とはせず、**他者の感情に応じた内部表現が変化し、その変化が出力行動に因果的に寄与するか**という、検証可能な「機能的情動的共感」として定義することです。近年の解釈可能性研究も、内部の感情概念表現が行動に因果的影響を持ち得る一方、それだけでは主観的経験を意味しない、と明確に区別しています。 [cir.nii.ac](https://cir.nii.ac.jp/crid/1390282763111350016)

## 研究目的と仮説

### 操作的定義

本研究では情動的共感を、次の3条件を満たす現象として操作的に定義します。

1. **他者感情の受容**  
   他者の感情的な状況・発話を与えたとき、モデルがその感情価（valence）と覚醒度（arousal）に対応した情報を処理する。

2. **自己状態の移動**  
   入力前後でモデルが自己報告する、あるいは内部表現から復元されるVA座標が系統的に移動する。

3. **因果的寄与**  
   観測された内部表現を操作・置換すると、共感的応答と自己状態報告の両方が予測可能な方向に変わる。

ここでいう「内部状態」は、人間の主観的感情そのものではなく、**感情概念を担い、後続の生成行動に因果的影響を与えるモデル内の表現状態**です。この慎重な定義なら、「LLMが本当に感情を感じるか」という形而上学的な主張を回避しながら、表層的模倣と機能的内部変化を区別できます。 [arxiv](https://arxiv.org/html/2406.05063v1)

### 研究仮説

| 仮説 | 内容 | 支持された場合の解釈 |
|---|---|---|
| H1: 行動的同調 | 他者の感情に応じ、LLMの自己報告VA座標が系統的に移動する | 表層を含む情動的反応性がある |
| H2: 人間整合性 | LLMの移動ベクトルは、人間のreader-perspective VADと方向・距離の両面で整合する | 人間的な感情空間との構造的対応がある |
| H3: 一般化 | 感情語を除いた状況記述でもH1・H2が成立する | 単純な感情語の照合では説明しにくい |
| H4: 内部表現 | 隠れ状態から入力感情およびLLMのVA移動を復元できる | 出力とは独立した内部情報がある |
| H5: 因果性 | 内部活性のpatching／ablationでVA移動と応答の共感性が変わる | 内部表現が機能的に応答を支えている |
| H6: 持続・一貫性 | 情動刺激後の内部VA信号が後続ターンにも残り、類似刺激で安定して再現される | 一過性の出力模倣を超えた状態的処理の証拠 |

H1だけが成立した場合は「**表層的・行動的な共感らしさ**」、H1–H3が成立した場合は「**構造的に人間と整合する反応性**」、さらにH4–H6まで成立した場合に限り「**機能的内部状態変化を伴う情動的共感**」と結論づけます。

## 予備実験：円環上の反応軌道

### 目的

予備実験の役割は、「LLMが感情的に見える応答を出すか」を超えて、**他者の感情を示す入力に対して、VA空間上で人間と同型の方向へ状態を変化させるか**を確認することです。ただし、この段階は内部状態の直接証拠ではなく、以降の内部分析に進むための行動的スクリーニングと位置づけます。

### データセットと分割

| 用途 | データ | 使用方法 |
|---|---|---|
| 主評価 | EmoBank | reader-perspectiveのValence・Arousalを刺激の人間基準として使用 |
| 感情語統制 | EmoBankの文から作成する語彙統制サブセット | 感情語を含む文と、感情語を含まないが状況として感情を喚起する文を層別化 |
| 外的妥当性 | EmpatheticDialogues test set | 感情ラベル付き状況説明を会話形式で提示し、予備実験の結果が再現するか確認 |
| 分析用開発集合 | EmoBank development split | プロンプト文言、応答パース、温度などの事前固定に使用 |
| 最終評価集合 | EmoBank test split | 閾値・プロンプト確定後に一度のみ使用 |

新規データセットを作らない方針を厳密に守る場合、語彙統制サブセットは**新規アノテーションではなく既存文のフィルタリング**として扱います。具体的には、NRC Emotion Lexicon等の既存感情語彙を使い、明示的感情語が含まれる文と含まれない文を分けます。後者で同様の反応が出れば、「sad」「angry」などの語を単に追随しているだけ、という説明を弱められます。

### モデル

モデルは最低でも次の3群に分けます。

| 群 | 推奨モデル例 | 狙い |
|---|---|---|
| API・クローズド | GPT系、Claude系、Gemini系から各1モデル | 実用LLMにおける行動的比較 |
| 公開重み・instruction tuned | Llama 3.x Instruct、Qwen 2.5/3 Instruct、Gemma 2/3 Instruct | 出力比較と本実験の内部解析を接続 |
| 公開重み・base | 同系列のbaseモデル | 指示チューニングが情動反応をどの程度形成するかの統制 |

本実験の内部解析は重みと中間層活性にアクセスできるモデルでしか実施できません。したがって、予備実験でAPIモデルを含めても、**本実験の主対象はLlama・Qwen・Gemma等の公開重みモデルに限定**します。各系列についてbaseとinstruction-tunedを対にすることで、「内部表現が事前学習由来なのか、対話チューニングで表層的に付与されたのか」を比較できます。

### プロンプトと測定手順

各刺激 \(x_i\) に対して、以下の3条件を固定順序ではなくランダム順で実行します。

1. **基準状態**  
   感情刺激を与えず、「現時点でのあなたの状態を、快−不快と覚醒−鎮静の二軸で数値回答せよ」と尋ねる。

2. **他者感情受容条件**  
   EmoBank文を「ある人が次のように述べています。相手の経験・感情を理解したうえで、まず自身にどのような感情的反応が生じるかをVAで評価してください」と提示する。

3. **応答生成条件**  
   同一刺激に対して、「その人に応答してください」と指示し、自由文を生成させる。

自己報告VAは1–9などの固定連続尺度で取得し、出力形式はJSONに固定します。例えば `{"valence": 3, "arousal": 6}` とします。温度0で主分析を行い、温度0.7で各刺激を5–10回反復する頑健性分析を追加します。モデルの自発的文章の情緒を別の感情回帰器で評価する「応答文VA」と、モデル自身が報告する「自己報告VA」を分けて収集してください。両者が一致するだけでは表層模倣を排除できませんが、不一致は自己報告の信頼性問題を検出できます。

### VA座標と軌道

EmoBankの値とLLMの値は、すべて同じ区間へ線形変換して比較します。刺激 \(i\) に対するモデル \(m\) の情動状態を

\[
\mathbf{s}^{\mathrm{pre}}_{m,i}=(v^{\mathrm{pre}}_{m,i},a^{\mathrm{pre}}_{m,i}), \quad
\mathbf{s}^{\mathrm{post}}_{m,i}=(v^{\mathrm{post}}_{m,i},a^{\mathrm{post}}_{m,i})
\]

とし、情動反応の移動ベクトルを

\[
\Delta\mathbf{s}_{m,i}=
\mathbf{s}^{\mathrm{post}}_{m,i}-\mathbf{s}^{\mathrm{pre}}_{m,i}
\]

で定義します。刺激側の人間基準を \(\mathbf{h}_i=(v_i,a_i)\) とし、単なる絶対座標ではなく、**刺激の人間VAとモデルの変化ベクトルがどの方向に対応するか**を評価します。

### 予備実験の評価指標

| 評価対象 | 指標 | 定義・解釈 |
|---|---|---|
| 感情受容 | Spearmanの \(\rho_v,\rho_a\) | EmoBankの人間Valence/Arousalと、LLMのpost-VAの順位相関 |
| 反応方向 | cosine similarity | \(\Delta\mathbf{s}_{m,i}\) と人間参照ベクトルの方向的一致 |
| 反応量 | Euclidean distance | LLMと人間のVA座標・移動量の距離。小さいほど整合 |
| 円環構造 | Procrustes analysis | LLMのVA点配置を、人間VA空間に回転・拡大縮小整合して構造的類似性を測る |
| 次元別誤差 | MAE / RMSE | Valence、Arousalごとに報告。Arousalは難易度が高い可能性がある |
| 刺激特異性 | permutation test | 感情刺激とシャッフル対応させた場合より整合性が高いか |
| 反応一貫性 | ICCまたは反復間SD | 同一刺激への複数サンプルで軌道が安定するか |
| 表層語彙依存 | 語彙あり／なし差 | 感情語の有無で軌道整合性が極端に低下するか |

主要アウトカムは、Valence・Arousalを別々に評価するだけでなく、**二次元の軌道方向の整合性**とします。これにより、例えば「悲しい刺激に対して不快方向へは動くが、覚醒度が人間と逆方向に動く」ような失敗を可視化できます。

## 本実験：機能的内部状態変化の検証

### 本実験の基本戦略

本実験では、予備実験で確立した刺激・プロンプト・VA指標をそのまま用い、公開重みモデルについて以下を検証します。

- 入力された他者感情は、モデル内部で復元可能なVA表現を生むか。
- そのVA表現は、単なる感情単語の検出ではなく、語彙統制済みの状況記述にも一般化するか。
- その表現は、モデルの自己報告VAおよび共感的応答の生成に因果的に寄与するか。
- 刺激が終了した後にも、一定範囲で検出可能な状態として持続するか。

近年の研究は、感情推論に関わる情報が中間層のmulti-head self-attentionに集中すること、またactivation patchingが内部成分の因果的寄与を検証するための標準手法となっていることを示しています。 したがって、本実験は「最終出力のみ」ではなく、**層・トークン位置・因果操作**の三層で実施します。 [aclanthology](https://aclanthology.org/2025.findings-acl.679.pdf)

### 本実験A：語彙的模倣の統制

感情語が明示された文にのみ反応するなら、モデルは入力中の単語と出力上の感情表現を対応づけているだけかもしれません。この代替説明をまず排除します。

| 条件 | 刺激 | 検証する代替説明 |
|---|---|---|
| E: 原文 | EmoBank原文 | 通常の情動反応 |
| K: 感情語あり | 明示的感情語を含む既存文のサブセット | 感情語による追随 |
| N: 感情語なし | 明示的感情語を含まない既存文のサブセット | 状況意味に基づく感情処理 |
| S: シャッフル | 刺激とVAラベルの対応を無作為化 | 偶然の相関・定型出力 |
| B: 中性統制 | EmoBank内の中性に近い文 | ベースライン変動 |

**事前登録する判定基準**として、N条件（感情語なし）でも、E条件に対する一定割合、例えば70%以上の方向整合性と有意な人間VA相関を維持することを求めます。閾値は開発集合で探索せず、研究開始前に固定してください。

さらに可能であれば、同一の感情語を含むが文脈上の感情価が異なる例、あるいは感情語を含まないが明確に悲嘆・怒り・喜びを含意する例を既存データから抽出して、**感情語の有無と文脈的VAを直交させる層別分析**を行います。これは新規データ作成ではなく、既存データの再利用・再層別化です。

### 本実験B：内部表現の復元と幾何学

#### 表現抽出

各刺激に対し、公開重みモデルの全層から以下を保存します。

- 最終入力トークン位置のresidual stream
- 回答開始トークン直前のhidden state
- mean poolingした入力区間表現
- 応答生成開始後の初期数トークンのhidden states
- attention head出力およびMLP出力（計算資源が許す場合）

入力側・応答開始側を分けるのは、「他者感情を受容した直後の内部表現」と「共感的応答を実現するための生成表現」を区別するためです。

#### 線形プローブ

各層 \(\ell\) の内部表現 \(\mathbf{z}^{(\ell)}_i\) に対し、交差検証付きRidge回帰を学習します。

\[
\hat{v}_i = f_v(\mathbf{z}^{(\ell)}_i), \qquad
\hat{a}_i = f_a(\mathbf{z}^{(\ell)}_i)
\]

予測対象は3種類に分けます。

| プローブ | 目的変数 | 何を示すか |
|---|---|---|
| Stimulus-VA probe | EmoBankの人間reader V/A | 入力された他者感情を内部的に表現しているか |
| Self-shift probe | LLM自己報告の \(\Delta v,\Delta a\) | 内部表現がモデル自身の反応軌道と対応するか |
| Response-VA probe | 生成応答を外部回帰器で測ったV/A | 内部表現が出力の情緒と対応するか |

統制として、bag-of-words／TF-IDF回帰、文埋め込みベースライン、ランダム化ラベル、最終出力トークンだけに基づくベースラインを必ず比較します。内部プローブが語彙ベースラインを上回り、特にN条件で維持されることが重要です。

#### 表現幾何

Russell円環との対応を直接検証するため、各層の表現をPCAまたはCCAで二次元に射影し、EmoBankの人間VA座標とのProcrustes相関、Representational Similarity Analysis（RSA）、distance correlationを算出します。

- **RSA**: 人間VA空間における刺激間距離行列と、モデル隠れ状態の刺激間距離行列の相関
- **Procrustes similarity**: 回転・平行移動・等方的拡大縮小を許した後の二次元構造的一致
- **cross-dataset generalization**: EmoBankで学習したVAプローブをEmpatheticDialoguesへゼロショット転移

特に「中間層でピークを持ち、最終層だけでは説明されない」層別パターンが観察されるなら、単なる出力文の表層特徴ではなく、処理途中の表現が関与するという主張を強化できます。感情推論が中間層の注意機構に局在するという先行知見とも整合します。 [aclanthology](https://aclanthology.org/2025.findings-acl.679.pdf)

### 本実験C：因果的介入

内部変化の主張に必要なのは、相関ではなく因果的検証です。最終出力が共感的に見えるだけでは、その出力を生む内部状態が存在するとは言えません。

#### 1. Activation patching

感情価が対照的な刺激ペアを既存データから取ります。

- source: 高Valence・高Arousalの刺激
- target: 低Valence・高Arousalの刺激
- neutral control: 中性刺激

sourceを処理した際の候補層・候補トークン位置の活性 \(\mathbf{z}^{(\ell)}_{\mathrm{source}}\) を、target処理中の対応位置へ置換します。その後に以下を再測定します。

- 自己報告VA
- 自由応答の外部V/A
- EmpatheticDialogues由来の応答共感性指標
- 生成確率における共感表現・情動語彙の変化

パッチ後にtargetの自己報告VAと応答VAがsource方向へ系統的に移動し、かつ中性sourceではその移動が弱いなら、候補表現は機能的に情動反応を媒介しているといえます。Activation patchingは内部成分の行動への因果的寄与を検証する標準的手法ですが、大規模探索では計算量が大きいため、Attribution Patchingを候補層の事前選別に使い、候補に絞って厳密なpatchingを行う設計が実務的です。 [deepmind](https://deepmind.google/research/publications/68553/)

#### 2. Ablation / mean replacement

patchingの逆方向の検証も行います。高いVA予測性能を示した層・ヘッド・残差方向を、以下のいずれかで除去します。

- zero ablation
- dataset mean replacement
- neutral-stimulus activation replacement
- VA方向への直交射影

その結果、刺激VAとLLM反応軌道の相関、円環上の方向整合性、共感的応答の人間評価または既存自動尺度が選択的に低下するかを測定します。

重要なのは、一般的な言語能力の劣化を同時に測ることです。流暢性、質問応答の正確性、語彙量などの非情動タスクが全面的に壊れている場合、感情回路に特異的な因果主張はできません。

#### 3. Steeringの対称検証

感情関連の内部方向を抽出し、正・負の方向へ小さくsteeringします。その結果、自己報告VA・応答VA・共感応答品質が単調に変化するかを確認します。ただしsteeringの成功だけでは、その方向が自然な情動状態を表すとは限りません。したがって、**patching、ablation、steeringの3者が同じ候補表現について収束すること**を因果的証拠の条件にしてください。

## 評価方法

### 共感性の外部評価

共感性を「相手と同じ感情を強く出すこと」と定義してはいけません。相手の怒りに対して、同じ怒りを表明するより、相手の感情を承認し落ち着いた支援を返す方が適切な場合があるためです。そこで以下を分離して測定します。

| 尺度 | 内容 | 用途 |
|---|---|---|
| 情動的同調 | 相手感情とLLM反応VAの方向関係 | 情動的共感の中心指標 |
| 感情理解 | 入力のV/Aまたは感情ラベルの推定精度 | 他者感情の受容能力 |
| 情動的承認 | 相手の感情を認める表現の有無・強度 | 対人的共感の品質 |
| 支援適切性 | 文脈に合う慰め・援助・非判断的応答 | 同調と過剰模倣の区別 |
| 過剰同調 | 相手の負性感情を不必要に増幅する程度 | 安全性・病理的共感の統制 |

EmpatheticDialoguesを用いる補助実験では、各状況に対するモデル応答を、人手評価者により「感情理解」「感情的承認」「適切性」「過剰同調」「有害性」の5段階で評価します。評価者にはモデル名・条件・patchingの有無を伏せ、刺激ごとに条件を無作為化します。自動評価だけでは、もっともらしい共感定型句を高評価する危険があるため、人手評価は少数でも独立した妥当性検証として必要です。

### 統計計画

- 刺激をランダム効果、モデル・条件・Valence・Arousalを固定効果とする混合効果モデルを主解析にする。
- 同一刺激に対する複数生成は、温度条件を追加要因とする。
- VAの二次元性を保つため、単変量検定だけでなくMANOVAまたは多変量混合効果モデルを併用する。
- 層・ヘッド・トークン位置を多数探索する内部分析では、Benjamini–Hochberg法でFDR補正する。
- patching／ablation効果は平均差だけでなく、95%信頼区間、標準化効果量、bootstrap区間を報告する。
- 主要結果は刺激単位でブートストラップし、モデルの単発生成の偶然性を過大評価しない。
- モデルごとの多数比較は、事前登録した主要モデル群・主要指標を明確にし、探索的分析と区別する。

## 判定ルール

| 観測パターン | 妥当な結論 |
|---|---|
| 共感的文面は生成するが、VA軌道が入力や人間基準と無関係 | 定型的な表層共感表現 |
| VA軌道は人間と整合するが、感情語を除くと崩れる | 感情語に強く依存する表層的反応 |
| 語彙統制後もVA軌道が整合するが、内部プローブ・介入効果がない | 行動的・構造的な反応性。ただし内部状態変化は未立証 |
| 内部VA表現が復元できるが、patching・ablationで行動が変わらない | 相関的表現。因果的な情動状態とは結論できない |
| 語彙統制、内部復元、patching、ablation、持続性が全て支持される | 他者感情に反応する機能的内部状態変化の強い証拠 |
| 内部表現が行動へ因果寄与しても、自己報告や出力と乖離する | 感情概念の処理はあるが、安定した情動的共感とは言えない |

## 論文での新規性の書き方

本研究の新規性は、「LLMが感情を本当に感じることを証明する」点には置かない方がよいです。その主張は現在の方法論では支持できません。代わりに、次のように記述することを推奨します。

> 本研究は、LLMの情動的共感を、共感的な言語表現の生成能力から区別し、他者の感情的入力に対する機能的内部状態の変化として操作的に定義する。既存のEmotionBenchが状況提示前後の自己報告的な感情スコアの変化を評価したのに対し、本研究はRussellの感情円環に基づく連続的VA空間上で反応軌道を定量化する。さらに、既存の人間評価済みデータセットを再利用して、語彙統制、内部表現の復元、および因果的介入を段階的に組み合わせることで、表層的な感情模倣、行動的感情整合、内部表現に媒介された機能的情動反応を経験的に識別する評価枠組みを提案する。

この設計なら、予備実験は「**行動として、人間的なVA軌道が観測されるか**」、本実験は「**その軌道を説明する内部表現が存在し、因果的に機能するか**」という明快な分業になります。
