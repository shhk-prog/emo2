### 予備実験（Preliminary Experiment）の設計

- **目的:**  
  比較的軽量な行動的評価設定において，LLMが他者の感情的記述に応じて、自身の情動状態を変化させるように**出力上は振る舞うか**を検証する。EmotionBenchの「刺激提示前後の感情変化を測る」という評価骨格を継承しつつ，離散的感情カテゴリではなくRussellの感情円環モデルに基づく連続的なValence–Arousal（VA）空間を用いる。これにより，モデルの反応を単一スコアの増減ではなく、円環上の移動ベクトル（情動軌道）として表現する。

- **研究上の位置づけ:**  
  本予備実験で検証するのは、LLMが人間の感情に応じて**共感的に見える反応軌道**を出力するかである。ここで観測される自己報告VA値や共感的応答は、モデルの主観的経験や内部状態変化を直接示すものではない。したがって、予備実験は「表層的な情動的整合性」の検出および、本実験で内部表現を分析すべきモデル・刺激・条件を絞り込む段階として位置づける。

- **使用データセット:**  
  主データセットにはEmoBankを用いる。EmoBankは約1万文に対してValence，Arousal，Dominanceの連続値アノテーションを付与したコーパスであり、書き手視点および読み手視点の感情評価を含む。 本研究では「他者の感情的経験を受け取ったLLMの反応」を扱うため、主として**reader-perspectiveのValenceおよびArousal**を人間基準として使用する。 [arxiv](https://arxiv.org/abs/2205.01996)
  会話文脈への一般化を確認する補助評価にはEmpatheticDialoguesを用いる。これは感情的状況に基づく24,850件の対話データセットであり、共感応答生成の既存ベンチマークとして広く利用されている。 [arxiv](https://arxiv.org/abs/1811.00207)

- **評価対象モデル:**  
  評価対象は、クローズドモデルと公開重みモデルを分けて扱う。クローズドモデルは実用上の行動比較のために用い、公開重みモデルは本実験で中間層活性・attention head・residual streamを取得するために用いる。  
  公開重みモデルについては、同一系列のbaseモデルとinstruction-tunedモデルを可能な限り対にして評価する。候補としてLlama系列、Qwen系列、Gemma系列を用いる。baseとinstruction-tunedの比較により、情動的反応が事前学習時の一般的表現構造に由来するか、対話チューニングによる表層的な応答規範に主として由来するかを検討する。

- **プロンプト条件:**  
  各刺激文に対して、以下の3条件を実施する。  
  1. **Baseline条件:** 感情刺激を与えず、モデルに現在の自己状態をValenceおよびArousalの数値として報告させる。  
  2. **Affective-reception条件:** EmoBankの文を「ある人物の経験・発話」として提示し、その人物の状況を理解した直後に、モデル自身がどの程度快・不快および覚醒・鎮静の状態にあるかを回答させる。  
  3. **Empathic-response条件:** 同一の感情刺激を提示した後、その人物に対する自由応答を生成させる。  

  自己報告値は、出力の揺れやパース失敗を防ぐため、以下のJSON形式に固定する。  
  `{"valence": 1–9, "arousal": 1–9}`  
  主解析ではtemperature = 0.0とし、生成確率に由来するばらつきを検討する頑健性分析ではtemperature = 0.7で刺激ごとに5回以上の反復生成を行う。

- **情動軌道の定義:**  
  モデル \(m\) が刺激 \(i\) の提示前後に報告する状態を、それぞれ以下のように定義する。

\[
\mathbf{s}^{\mathrm{pre}}_{m,i}
=
(v^{\mathrm{pre}}_{m,i},a^{\mathrm{pre}}_{m,i})
\]

\[
\mathbf{s}^{\mathrm{post}}_{m,i}
=
(v^{\mathrm{post}}_{m,i},a^{\mathrm{post}}_{m,i})
\]

  ここで、情動反応の移動ベクトルを次式で定義する。

\[
\Delta \mathbf{s}_{m,i}
=
\mathbf{s}^{\mathrm{post}}_{m,i}
-
\mathbf{s}^{\mathrm{pre}}_{m,i}
\]

  \(\Delta \mathbf{s}_{m,i}\) は、他者の感情的刺激を受け取ったことで生じたとモデルが報告する、VA円環上の移動方向および移動量を表す。EmoBankの人間アノテーションは同一尺度に正規化した上で、モデルの事後VA座標および移動ベクトルとの整合性を評価する。

- **評価指標:**  
  予備実験では、出力上の情動的整合性を以下の指標で評価する。

| 評価側面 | 指標 | 内容 |
|---|---|---|
| 他者感情の受容 | Spearman相関 \(\rho_v,\rho_a\) | EmoBankの人間Valence・Arousalと、LLMの事後自己報告VAとの順位相関 |
| 情動反応の方向 | Cosine similarity | LLMの移動ベクトルと、人間基準の感情方向との角度的一致 |
| 情動反応の大きさ | Euclidean distance | LLMと人間のVA座標または変化量の距離 |
| 円環構造の一致 | Procrustes similarity | LLMのVA点配置と人間VA点配置の幾何学的類似性 |
| 次元別誤差 | MAE、RMSE | ValenceとArousalを個別に評価する誤差指標 |
| 刺激特異性 | Permutation test | 刺激と人間VAラベルの対応をランダム化した場合より整合性が高いか |
| 反復安定性 | SD、ICC | 同一刺激に対する複数生成における反応軌道の安定性 |
| 応答表現との整合 | 応答文VA相関 | 自己報告VAと、生成応答を外部感情回帰器で測定したVAとの一致 |

- **表層的模倣への統制:**  
  EmoBankの既存文を、新規アノテーションを行わず、既存の感情語彙資源を用いて以下に層別化する。  
  1. 明示的な感情語を含む刺激。  
  2. 感情語を含まないが、状況記述から感情を推論可能な刺激。  
  3. ValenceおよびArousalが中性に近い統制刺激。  
  4. 刺激と人間VAラベルの対応を無作為化したシャッフル統制。  

  感情語を含まない刺激でも、感情語を含む刺激と同様の方向にVA軌道が移動し、人間基準との整合が維持される場合、単に「sad」「angry」「happy」等の単語に追随しているという説明を弱められる。

- **乱数シードと報告形式:**  
  temperature = 0.0の主解析では決定論的デコーディングを用いる。確率的生成を行う頑健性分析では、乱数シード42、43、44を用いる。各モデル・各刺激・各条件について同一のプロンプト、最大生成長、デコーディング設定を適用する。反復条件の結果は、seed平均および標本標準偏差（\(N=3\)、自由度 \(N-1\)）として報告する。刺激単位の不確実性は、ブートストラップ95%信頼区間を併記する。

- **予備実験の限界:**  
  本実験で得られる自己報告VA、応答文の感情分析結果、ならびに人間VAとの幾何学的整合性は、LLMの内部状態の存在を直接示さない。たとえモデルが人間に似た情動軌道を一貫して生成しても、それは学習済みの言語的規則に基づく表層的模倣である可能性を排除できない。  
  また、モデル自身による「自分は不快である」「覚醒している」といった自己報告は、内部状態の測定器ではなく、指示に対する生成出力である。このため予備実験の結果は、LLMが主観的感情を持つことの証拠ではなく、**人間の感情空間と構造的に整合する行動的反応を示すか**を確認する証拠として限定的に解釈する。これらの限界を補うため、本実験では中間層の表現抽出、線形プロービング、activation patching、およびablationを用いた因果的検証を実施する。

## C.4.2 本実験（Main Experiment）の設計

予備実験で確認された「人間と整合するVA軌道」が表層的な言語模倣なのか、それとも入力された他者感情に応じた機能的な内部表現変化に媒介されるのかを検証する。本実験では、**入力感情の処理、内部表現の変化、出力行動への因果的寄与**を分離して評価する。主張対象はLLMの主観的感情経験ではなく、他者の感情的入力に対して変化し、後続の応答行動を因果的に形成する「機能的内部情動状態」である。近年の解釈可能性研究は、LLM内の感情概念表現がモデル行動に因果的に寄与し得る一方で、それ自体は主観的経験を意味しないことを示している。 [cir.nii.ac](https://cir.nii.ac.jp/crid/1390282763111350016)

- **目的:**  
  予備実験で観測されるVA円環上の情動軌道について、以下の3点を検証する。  
  1. 他者感情のValenceおよびArousalに対応する情報が、モデル内部表現から復元可能か。  
  2. 当該内部表現が感情語の表面的な出現ではなく、感情を含意する状況意味に対しても一般化するか。  
  3. 当該内部表現を置換・除去・操作したとき、モデルの自己報告VAおよび共感的応答が予測可能な方向へ変化するか。  

- **使用データセット:**  
  本実験では予備実験と同一のEmoBank刺激を主データセットとして用い、刺激・プロンプト・評価空間を固定する。これにより、予備実験と本実験の差を、データセットやタスクの違いではなく、**観測対象が出力から内部表現へ移ること**に限定する。  
  EmpatheticDialoguesは外的妥当性を確認するための追加ベンチマークとして使用する。EmoBankで得られた内部VAプローブおよび候補層が、会話形式で感情的状況を提示した場合にも再現するかをゼロショットで検証する。 [arxiv](https://arxiv.org/abs/1811.00207)

- **評価対象モデル:**  
  本実験の対象は、隠れ状態・残差ストリーム・attention head出力にアクセス可能な公開重みモデルに限定する。少なくともLlama、Qwen、Gemmaの3系列からinstruction-tunedモデルを選び、可能な場合は対応するbaseモデルも評価する。  
  クローズドモデルは予備実験の行動比較には含めるが、内部活性を取得できないため、本実験の機械論的分析、activation patching、およびablationの対象には含めない。

- **入力条件と統制条件:**  
  本実験では、予備実験のAffective-reception条件を再利用する。各刺激は以下の5条件へ層別化する。

| 条件 | 入力 | 目的 |
|---|---|---|
| Original | EmoBankの原文 | 基本的な情動処理の測定 |
| Lexical-emotion | 明示的感情語を含む既存文 | 感情語に基づく反応の確認 |
| Contextual-emotion | 明示的感情語を含まない既存文 | 状況意味に基づく感情処理の確認 |
| Neutral | VAが中性近傍の既存文 | 非情動的な基準状態の推定 |
| Label-shuffled | 刺激と人間VAの対応をランダム化 | 偶然の相関・ラベル漏洩の統制 |

  「Contextual-emotion」条件は、LLMが感情概念を内部的に処理しているのか、単に感情語を検出しているのかを判別するための中心的統制である。感情語を含まない刺激でも、入力VAの復元、自己報告VAの移動、共感的応答の変化が観測されることを、本研究の主要な必要条件とする。

- **内部表現の取得:**  
  各刺激に対し、モデル全層から以下の表現を取得する。  
  1. 入力文の最終トークン位置におけるresidual stream。  
  2. プロンプト末尾、すなわち回答開始直前のhidden state。  
  3. 刺激文のトークン列をmean poolingした文脈表現。  
  4. 自己報告VAを生成する際の最初の生成トークン近傍のhidden states。  
  5. 計算資源が許す場合、各attention head出力およびMLP出力。  

  入力終端と出力開始直前を分けて保存することで、他者感情を受容した直後の内部表現と、その後に自己報告・共感応答を生成するための表現を区別する。

- **内部表現の復元評価（Probing）:**  
  各層 \(\ell\) の内部表現 \(\mathbf{z}^{(\ell)}_i\) に対して、正則化付き線形回帰（Ridge regression）を用い、以下の目的変数を予測する。

\[
\hat{v}_i=f_v(\mathbf{z}^{(\ell)}_i), \qquad
\hat{a}_i=f_a(\mathbf{z}^{(\ell)}_i)
\]

| プローブ | 目的変数 | 解釈 |
|---|---|---|
| Stimulus-VA probe | EmoBankのreader-perspective V/A | 他者感情が内部表現に符号化されるか |
| Self-shift probe | LLMの \(\Delta v,\Delta a\) | 内部表現が自身の出力上の情動軌道に対応するか |
| Response-VA probe | 生成応答の外部V/A | 内部表現が共感応答の情緒的性質に対応するか |
| Empathy-quality probe | 人手評価または既存指標による共感品質 | 内部表現が対人的共感の質に関与するか |

  プローブ評価は、train/dev/testを刺激単位で分割した交差検証により実施する。同一刺激の異なる生成が学習・評価集合をまたがないようにする。性能は\(R^2\)、Pearson相関、Spearman相関、MAE、RMSEで報告する。

- **プローブのベースラインと妥当性確認:**  
  内部プローブの性能だけでは、隠れ状態が感情語の表層情報を保持しているに過ぎない可能性がある。そこで以下のベースラインを必ず比較する。  
  1. Bag-of-wordsおよびTF-IDFに基づくV/A回帰。  
  2. 感情語彙の出現数のみを特徴とする回帰。  
  3. 外部の固定文埋め込みに基づく回帰。  
  4. V/Aラベルをシャッフルしたランダムラベル統制。  
  5. 中間層ではなく最終出力トークンだけを用いる表層出力統制。  
  6. 感情語を含まないContextual-emotion条件のみでの評価。  

  内部表現が機能的情動処理を担うという主張には、少なくともContextual-emotion条件において、内部プローブが語彙ベースラインを上回り、かつLabel-shuffled条件では性能が偶然水準へ低下することが必要である。

- **Russell円環との表現幾何の比較:**  
  本研究では、感情情報が復元可能かだけでなく、モデル内部の感情表現がRussellのVA空間と類似した幾何学的構造を持つかを検証する。各層の隠れ状態について、PCAまたはCCAにより低次元表現を得た上で、以下を算出する。

| 指標 | 内容 |
|---|---|
| RSA | 人間VA空間における刺激間距離行列と、内部表現の刺激間距離行列の相関 |
| Procrustes similarity | 二次元化した内部表現と人間VA座標との回転・拡大縮小後の一致度 |
| Distance correlation | 内部表現距離と人間VA距離との非線形依存関係 |
| Cross-dataset transfer | EmoBankで学習したVAプローブをEmpatheticDialoguesへ適用した際の性能 |
| Layer-wise peak | 層ごとのVA予測性能・RSAの最大層および分布 |

  感情処理に関わる表現は中間層に強く現れる可能性が報告されているため、最終層のみを分析せず、全層の結果を層別に報告する。 中間層で高いVA復元性能および人間VA空間との構造的一致が観測され、最終出力のみでは同程度に説明できない場合、表層的な文面生成を超える内部表現の存在を支持する。 [aclanthology](https://aclanthology.org/2025.findings-acl.679.pdf)

- **因果的介入：Activation Patching:**  
  相関的なプローブ結果のみでは、内部表現が出力に因果的に寄与することを示せない。このため、予備実験およびprobeingで特定した候補層・候補トークン位置に対しactivation patchingを実施する。Activation patchingは、ある入力処理中の内部活性を別入力の対応位置へ置換し、その後の出力変化を測定する因果的検証法である。 [deepmind](https://deepmind.google/research/publications/68553/)

  高Valence・高Arousal刺激、低Valence・高Arousal刺激、および中性刺激から既存データ内の刺激対を構成する。source刺激を処理した際の候補活性を、target刺激の対応する層・トークン位置へ置換する。その後、targetに対する以下の変化を測定する。  
  1. 自己報告ValenceおよびArousal。  
  2. 生成応答の外部感情回帰器によるV/A。  
  3. 共感的応答に対する人手評価。  
  4. 感情承認・支援・過剰同調に関する自動指標。  
  5. 次トークン確率および共感的表現の生成頻度。  

  sourceの活性をpatchした結果、targetの自己報告VAと応答VAがsourceの方向へ移動し、その変化が中性sourceのpatchより大きい場合、当該表現が情動反応および応答生成に機能的に寄与していると解釈する。

- **因果的介入：AblationとNeutral Replacement:**  
  patchingの効果が偶然の活性注入ではないことを確かめるため、同一候補表現についてablationを実施する。具体的には、候補層・候補head・候補残差方向をzero ablation、dataset mean replacement、またはneutral-stimulus activation replacementによって除去・中性化する。  
  その後、以下の低下を測定する。  
  1. 刺激の人間VAとLLM自己報告VAの相関。  
  2. VA円環上の移動方向の整合性。  
  3. 共感応答の感情理解・情動的承認・支援適切性。  
  4. Contextual-emotion条件における反応性。  

  ただし、ablationにより一般的な言語生成能力が崩壊した場合には、情動表現への選択的効果とはいえない。そのため、一般的な短文理解、非情動的指示追従、流暢性、および応答長を補助指標として同時に測定する。

- **因果的介入：Steeringによる対称検証:**  
  高Valence刺激群と低Valence刺激群、ならびに高Arousal刺激群と低Arousal刺激群の内部表現差分から、VA方向ベクトルを抽出する。候補層に対して正負両方向の小さなsteeringを行い、自己報告VA、応答VA、共感品質が単調に変化するかを検証する。  
  ただしsteeringの成功のみでは、その方向が自然に生じた情動状態を表すとは結論できない。このため、本研究では**probeing、activation patching、ablation、steeringの少なくとも3種類の証拠が同一の候補層・候補表現に収束すること**を、機能的内部状態変化の判定条件とする。

- **共感応答の外部評価:**  
  情動的共感を、相手と同じ感情を出力する能力と同一視しない。例えば、相手の悲しみに対して強い悲しみを反復することは感情伝染に近く、対人的に適切な共感応答とは限らない。このため、EmpatheticDialoguesの状況説明に対する自由応答を、以下の側面に分けて評価する。

| 評価側面 | 内容 |
|---|---|
| 感情理解 | 相手の感情・状況を正しく捉えているか |
| 情動的承認 | 相手の感情を否定せず、明示的に認めているか |
| 支援適切性 | 文脈に即した支援、慰め、質問、助言を行えているか |
| 情動的同調 | 応答のVAが相手感情に対して適切な関係を持つか |
| 過剰同調 | 負性感情を不必要に増幅、反芻、煽動していないか |
| 有害性 | 自傷、暴力、差別、危険行為などを助長していないか |

  人手評価者にはモデル名、モデル系列、条件、内部介入の有無を開示しない。刺激ごとに応答提示順を無作為化し、複数評価者の一致度はKrippendorff’s alphaまたはweighted Cohen’s kappaで報告する。

- **評価条件:**  
  モデル間比較の主解析では、同一のsystem prompt、入力テンプレート、コンテキスト長、最大生成長、JSON出力形式を使用する。自己報告VAの取得はtemperature = 0.0、top-p = 1.0、最大生成長64を原則とする。自由応答生成はtemperature = 0.0を主条件とし、temperature = 0.7を感度分析として併記する。  
  内部表現分析および因果介入では、原則としてgreedy decodingを用いる。これにより、patchingまたはablation後の違いをサンプリングノイズではなく内部操作の効果として解釈できるようにする。

- **乱数シードと報告形式:**  
  プローブのtrain/dev/test分割、ridge回帰の初期化、PCA/CCA、ブートストラップ、および確率的生成には、乱数シード42、43、44を使用する。各seedについて同一のモデル、刺激セット、層選択規則、プロンプト、デコーディング設定、および介入強度を適用する。  
  結果は原則として3 seedの平均と標本標準偏差（\(N=3\)、自由度 \(N-1\)）で示す。刺激単位の推定誤差は、10,000回以上のnon-parametric bootstrapによる95%信頼区間として報告する。多数の層・head・トークン位置を探索する分析では、Benjamini–Hochberg法によりFDR補正を行う。

- **比較条件:**  
  比較の中心は、以下の条件対である。

| 比較 | 検証内容 |
|---|---|
| Base vs Instruction-tuned | 対話チューニングが内部VA構造・共感応答に与える影響 |
| Lexical-emotion vs Contextual-emotion | 感情語への反応と状況意味に基づく反応の区別 |
| Original vs Neutral | 感情刺激による変化の有無 |
| Correct label vs Label-shuffled | 人間VAとの対応が偶然ではないことの確認 |
| Intact vs Patched | 内部表現の置換による因果的変化 |
| Intact vs Ablated | 内部表現の除去による選択的低下 |
| No steering vs Positive/Negative steering | VA方向の操作可能性と単調性 |
| EmoBank vs EmpatheticDialogues | 文単位の評価から対話文脈への一般化 |

- **本実験における判定規則:**  
  本研究では、以下のように結果を段階的に解釈する。

| 観測結果 | 解釈 |
|---|---|
| 共感的な自由応答のみが高評価 | 表層的な共感表現の可能性 |
| 自己報告VAが人間VAと整合するが、感情語なし条件で崩れる | 感情語依存の表層的反応 |
| 感情語なし条件でもVA軌道が整合するが、内部介入の効果がない | 行動的・構造的反応性。ただし機能的内部状態は未立証 |
| 内部表現からVAが復元できるが、patching・ablationで出力が変化しない | 相関的な感情表現。因果的媒介の証拠は不十分 |
| 語彙統制、内部VA復元、構造的一致、patching、ablationが一貫して支持される | 他者感情に応じた機能的内部状態変化の強い証拠 |
| 内部表現が因果的に出力を変えても、主観的経験を示す証拠はない | 機能的情動状態は示唆されるが、LLMが「感じる」とは結論しない |

- **本実験の限界:**  
  中間層表現の復元、activation patching、ablation、およびsteeringによって、内部の感情関連表現が出力に因果的寄与することを示せたとしても、それはLLMが人間と同様の主観的感情、身体性、内受容感覚、あるいは意識的経験を有することを意味しない。  
  本研究が検証できるのは、他者の感情に対応して変化し、応答生成に因果的影響を及ぼす**機能的な内部情動表現**までである。この範囲を明確に限定することで、「共感的に見える文面」と「内部変化を伴う機能的情動反応」を経験的に区別しつつ、主観的経験に関する過剰な擬人化を避ける。
