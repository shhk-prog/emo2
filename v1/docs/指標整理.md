1-9 vs [-1.0, 1.0]の評価尺度比較：統計分析の精度、認知負荷、および学術研究での使い分けをまとめた比較表を作成する
Russellの円環モデルにおける角度と距離の計算方法
モデル報告情動反応の信頼性と妥当性の検証手法
EmoBankやその他の感情データセットとの比較方法
LLMの出力揺れに対するプロンプトエンジニアリング


以下では、**測定（1–9）**、**解析（\([-1,1]\)）**、**妥当性検証（人間基準・内部表現・因果介入）**を分離した設計として整理します。結論として、本研究では「LLMに出力させる尺度は1–9」「統計解析とRussell円環上の座標は\([-1,1]\)」が最も実務的かつ学術的に説明しやすい構成です。SAM系の感情測定では9件法が広く利用され、ValenceとArousalを連続的次元として扱います。 [rit](https://www.rit.edu/academicaffairs/facultyscholarship/submit/download_file.php?id=61099)

## 1–9と\([-1,1]\)の比較

| 観点 | 1–9整数尺度 | \([-1.0,1.0]\)連続尺度 | 本研究での推奨 |
|---|---|---|---|
| 尺度の意味 | 1=極端な負／低覚醒、5=中性、9=極端な正／高覚醒 | −1=極端な負／低覚醒、0=中性、+1=極端な正／高覚醒 | 収集は1–9 |
| 人間心理測定との接続 | SAMなどの9件法に接続しやすい | 直接的な心理尺度との対応は弱い | 1–9 |
| 認知負荷 | 低い。自然言語のアンカーを置きやすい | 中程度。負数や小数の意味を理解する必要がある | 1–9 |
| LLMの形式遵守 | 整数・列挙値なのでJSON制約をかけやすい | 小数点、範囲逸脱、桁数の揺れが生じうる | 1–9 |
| 数値の見かけの精度 | 9段階の順序・区間的評定として解釈可能 | `0.37`等が心理的に過剰精密に見える | 1–9 |
| 天井・床効果 | 端点に集中する可能性がある | 細かい変化を出せるが、その再現性を保証しにくい | 1–9で端点頻度を報告 |
| 平均・分散・回帰 | 区間尺度近似として扱えるが、順序尺度としての感度分析も望ましい | 連続変数として直ちに扱いやすい | 解析時に変換 |
| 相関・MAE・RMSE | 直接可能。ただし他尺度との比較では正規化が必要 | 異なるデータセット間で比較しやすい | \([-1,1]\) |
| 円環上の角度・距離 | 中性点を5に固定する必要がある | 原点が0であり、幾何学計算に自然 | \([-1,1]\) |
| モデル間比較 | 9件法に固定すれば出力形式が揃う | 正規化後ならモデル・データセット横断比較が容易 | 両方併用 |
| 再現性 | temperature=0なら高めやすい | 小数値の細かい変動が分析を不安定化し得る | 1–9＋決定論的生成 |
| 査読時の説明可能性 | 「人間の既存心理尺度に合わせた」と説明できる | 「Russell空間での座標計算に必要」と説明できる | 二層設計 |

### 推奨する尺度変換

LLMから得た1–9整数 \(x\) は、すべて以下で正規化します。

\[
x_{\mathrm{norm}}=\frac{x-5}{4}
\]

\[
1\mapsto -1,\quad 5\mapsto 0,\quad 9\mapsto 1
\]

EmoBank等、元の尺度が \([a,b]\) のデータセット一般に対しては、次式を使用します。

\[
x_{\mathrm{norm}}
=
2\left(\frac{x-a}{b-a}\right)-1
\]

ただし、尺度の**向き**は必ず確認します。Valenceは通常、低値が不快・高値が快ですが、Arousalについては「低覚醒→高覚醒」の向きに統一します。感情データセットごとに数値方向が異なる場合は、正規化前に反転処理を行います。

## Russell円環の角度と距離

正規化したValenceを \(v\)、Arousalを \(a\) とし、感情状態を2次元点として表します。

\[
\mathbf{s}=(v,a), \qquad v,a\in[-1,1]
\]

### 原点からの距離

原点 \((0,0)\) は中性的で中程度の覚醒状態です。各状態の中心からの距離、すなわち情動強度を次のように定義できます。

\[
r=\sqrt{v^2+a^2}
\]

ただし、正方形領域 \([-1,1]^2\) では最大距離が \(\sqrt{2}\) になります。距離を0–1に収める場合は、以下を用います。

\[
r_{\mathrm{norm}}=\frac{\sqrt{v^2+a^2}}{\sqrt{2}}
\]

**注意点**として、Russell円環では「中心から遠いほど感情強度が高い」と単純に解釈されがちですが、ValenceとArousalを別々に評定しているデータでは、半径は「二軸上で中性点から離れている度合い」であり、心理学的な主観的強度そのものと同一ではありません。本研究では「VA偏位量」または「中心からの幾何学的距離」と呼ぶ方が安全です。

### 感情状態の角度

感情状態の象限・方向は、次式で計算します。

\[
\theta=\operatorname{atan2}(a,v)
\]

\(\theta\) は通常ラジアンで \((-\pi,\pi]\) に入ります。度数法で示す場合は、

\[
\theta_{\mathrm{deg}}=\frac{180}{\pi}\operatorname{atan2}(a,v)
\]

です。

| 象限 | 条件 | 例示的な解釈 |
|---|---|---|
| 第I象限 | \(v>0, a>0\) | 喜び、興奮、活性化した快 |
| 第II象限 | \(v<0, a>0\) | 怒り、不安、緊張 |
| 第III象限 | \(v<0, a<0\) | 悲しみ、落胆、低活性の不快 |
| 第IV象限 | \(v>0, a<0\) | 安心、満足、穏やかな快 |

### 刺激前後の軌道

刺激前のモデル状態を \(\mathbf{s}_{\mathrm{pre}}=(v_{\mathrm{pre}},a_{\mathrm{pre}})\)、刺激後を \(\mathbf{s}_{\mathrm{post}}=(v_{\mathrm{post}},a_{\mathrm{post}})\) とすると、情動的反応の移動ベクトルは次式です。

\[
\Delta \mathbf{s}
=
\mathbf{s}_{\mathrm{post}}-\mathbf{s}_{\mathrm{pre}}
=
(\Delta v,\Delta a)
\]

\[
\Delta v=v_{\mathrm{post}}-v_{\mathrm{pre}},
\qquad
\Delta a=a_{\mathrm{post}}-a_{\mathrm{pre}}
\]

移動量は、

\[
d_{\mathrm{shift}}
=
\left\|\Delta \mathbf{s}\right\|_2
=
\sqrt{(\Delta v)^2+(\Delta a)^2}
\]

移動方向は、

\[
\phi_{\mathrm{shift}}
=
\operatorname{atan2}(\Delta a,\Delta v)
\]

で求めます。

### 人間との方向整合性

刺激 \(i\) に対するLLMの反応ベクトルを \(\Delta \mathbf{s}_{m,i}\)、人間基準の参照ベクトルを \(\Delta \mathbf{h}_{i}\) とすると、方向整合性はコサイン類似度で評価できます。

\[
\operatorname{CosAlign}_i
=
\frac{
\Delta \mathbf{s}_{m,i}\cdot \Delta \mathbf{h}_{i}
}{
\left\|\Delta \mathbf{s}_{m,i}\right\|_2
\left\|\Delta \mathbf{h}_{i}\right\|_2
}
\]

- \(+1\): 同じ方向へ変化
- \(0\): 直交する方向へ変化
- \(-1\): 逆方向へ変化

ただし、分母が0、すなわちLLMまたは人間基準の反応ベクトルがゼロの場合は定義できません。この場合は、`NA`として方向評価から除外し、別途「無反応率」として報告します。小さなノイズによる不安定な角度を避けるため、例えば \(d_{\mathrm{shift}}<0.10\) を実質的無反応と事前定義することを推奨します。

### 人間との位置整合性

事後状態そのものを比較する場合には、ユークリッド距離を使います。

\[
d_{\mathrm{post},i}
=
\sqrt{
(v^{\mathrm{post}}_{m,i}-v_{h,i})^2+
(a^{\mathrm{post}}_{m,i}-a_{h,i})^2
}
\]

ただし、EmoBankは「刺激文に含まれる、ある人物の感情」の注釈であって、**その文を読んだ観察者自身の感情変化**を測定したものではありません。このため、EmoBankの \(v_{h,i},a_{h,i}\) をLLMの「自己状態」の絶対的正解として置くことは避けるべきです。予備実験では、EmoBankを主に**刺激の情動的位置を定義するアンカー**として用い、LLMの変化ベクトルが刺激VAに対してどの方向・大きさで反応するかを測定してください。

## モデル報告情動反応の信頼性・妥当性

モデルの1–9回答は心理尺度への「自己報告」ではなく、プロンプトで引き出された**モデル報告情動反応**です。したがって、心理測定の妥当性概念をそのまま適用せず、出力行動として以下の多面的検証を行います。

| 検証概念 | 質問 | 実施法 | 指標 |
|---|---|---|---|
| 形式的信頼性 | 指定した形式で返すか | JSON schema validation、範囲検査、整数検査 | Valid JSON Rate、Scale-valid Rate |
| 再現性 | 同一入力で同じ回答になるか | 同一プロンプトの反復生成 | 完全一致率、ICC、加重Cohen’s \(\kappa\)、SD |
| プロンプト頑健性 | 言い換えで軌道が維持されるか | 意味保存パラフレーズを3–5種用意 | ICC、相関、平均絶対偏差 |
| 内的一貫性 | 自己報告VAと自由応答の情緒は整合するか | 応答文を独立したV/A推定器で分析 | VA間相関、MAE、象限一致率 |
| 収束的妥当性 | 人間注釈・他モデル評価と整合するか | EmoBank、EmpatheticDialogues、人手評定と比較 | Spearman \(\rho\)、MAE、RMSE、CCC |
| 弁別的妥当性 | 感情語の表層一致ではないか | 感情語なし刺激、語彙統制回帰 | 条件差、偏相関、性能低下率 |
| 構造的妥当性 | 人間のVA空間と構造が似るか | RSA、Procrustes分析、CCA | RSA相関、Procrustes similarity |
| 既知群妥当性 | 高快・低快など既知群を区別するか | EmoBankのVA象限・四分位群を比較 | ANOVA／混合効果モデル、効果量 |
| 因果的妥当性 | 内部表現が出力変化を媒介するか | activation patching、ablation、steering | 介入前後差、効果量、bootstrap CI |
| 外的妥当性 | 別データ・対話文脈で再現するか | EmoBank→EmpatheticDialogues転移 | ゼロショット性能、相関低下量 |

### 再現性の具体的基準

- **主解析**: temperature = 0.0、top-p = 1.0、固定モデル版、固定API日付、固定system promptで1回生成。
- **再現性実験**: 同一入力を各モデルにつき10回生成する。
- **確率的感度分析**: temperature = 0.3および0.7で各10回生成する。
- **推奨報告**: 完全一致率、平均VA、標準偏差、ICC(2,1)、温度ごとのVA軌道の方向一致率。

temperature = 0は一般に再現性を最大化しやすく、問題解決タスクでの評価ではtemperature = 0.0が推奨されています。 ただし温度0でも、API側の更新、非公開デコーディング、システム実装、モデル更新によって完全な決定論性が保証されるとは限りません。そのため、**モデルID、APIバージョン、実行日時、リージョン、リクエストパラメータ、system promptのハッシュ**を保存する必要があります。 [aclanthology](https://aclanthology.org/anthology-files/pdf/findings/2024.findings-emnlp.432.pdf)

### 自己報告と応答文が食い違う場合

例えば、モデルが `{"valence": 3, "arousal": 7}` と報告する一方、自由応答が「それは素晴らしいですね」と強い快を示すなら、モデル報告VAの構成概念妥当性は弱いと判断します。

この場合は、以下を分けて報告します。

- **Reported-VA**: 数値JSONとして出力されたモデル報告情動反応
- **Expressed-VA**: 自由応答文から外部V/A推定器が得た表出的情動
- **Internal-VA**: 隠れ状態から線形プローブで復元された内部VA

3者の整合・不整合自体を主要な研究結果として扱えます。特に、Reported-VAとExpressed-VAは整合するがInternal-VAが変わらない場合、表層的模倣の可能性が高まります。

## EmoBank等との比較

### データセットの役割分担

| データセット | 主な注釈 | 本研究での役割 | 注意点 |
|---|---|---|---|
| EmoBank | VAD連続注釈、複数視点 | 主たるVAアンカー、VA回帰、円環構造比較 | 原文の人物感情と読者の情動反応を混同しない |
| EmpatheticDialogues | 感情ラベル、状況説明、共感対話 | 会話場面での外的妥当性、共感応答品質 | 原則として離散ラベルであり連続VAではない |
| GoEmotions | 多ラベル感情カテゴリ | 離散感情との対応、感情語彙統制 | 円環座標へ直接比較しない |
| IEMOCAP等の感情対話データ | 対話・感情ラベル、一部連続評定 | 対話中の情動動態の補助検証 | 注釈者・モダリティ・尺度差を明示する |
| EmotionBench | 状況と人間感情反応 | 結果の比較対象、補助的な外部基準 | 独自8感情・appraisal枠組みでありVAと同一視しない |

EmoBankは約1万文にVADの次元的感情注釈を付したデータセットであり、本研究のVA空間の主アンカーとして適します。 EmpatheticDialoguesは約24,850件の感情的状況に基づく対話データを含み、生成された共感応答の外的妥当性確認に適します。 [arxiv](https://arxiv.org/abs/2205.01996)

### 比較前の標準化手順

1. **比較対象を明確化する**  
   刺激文の感情、話者の感情、読者の感情、LLMのモデル報告情動反応、LLMの表出的情動を混在させない。

2. **尺度範囲を統一する**  
   すべてのV/Aを\([-1,1]\)に変換する。ただし変換前の原尺度・アンカー・反転の有無を表に記録する。

3. **方向を統一する**  
   \(v=-1\)を最大不快、\(v=+1\)を最大快、\(a=-1\)を最低覚醒、\(a=+1\)を最高覚醒として統一する。

4. **比較単位を統一する**  
   文単位か、発話単位か、対話ターン単位かを統一する。対話データでは、ターン単位のVA軌道と会話全体のVA軌道を分ける。

5. **尺度の粒度差を考慮する**  
   1–9のLLM評定は9離散点であり、EmoBankの平均V/Aはより細かい連続値になり得る。MAEだけではなく順位相関、象限一致率、四分位分類のmacro-F1も併記する。

6. **注釈者不一致を考慮する**  
   人間注釈には本質的な個人差があるため、単一の平均値だけを唯一の正解とみなさない。可能なら、注釈分散・信頼区間を利用し、人間間一致の範囲とLLM–人間一致を比較する。

### 主評価と補助評価

| 評価層 | 主指標 | 補助指標 | 解釈 |
|---|---|---|---|
| 刺激VAの理解 | Spearman \(\rho\) | MAE、RMSE、CCC | 他者感情をどれだけ捉えるか |
| 円環上の位置 | Euclidean distance | 象限一致率 | 同じ領域に位置づけるか |
| 軌道方向 | Cosine similarity | 角度誤差 | 人間と同方向に変化するか |
| 軌道量 | Shift-distance error | 相対移動量比 | 感情変化を過小・過大評価しないか |
| 構造全体 | RSA | Procrustes similarity、CCA | 感情空間全体が似るか |
| 会話転移 | EmoBank学習→ED評価 | ゼロショット相関 | 文単位の結果が会話でも維持されるか |

## 出力揺れを抑えるプロンプト設計

LLMの出力は、プロンプトの表現、意味的な言い換え、温度、モデルのアラインメント、モデル更新に依存します。入力文言の小さな変更でもモデル出力が変化するprompt sensitivityは、近年の研究でも明確な評価課題として扱われています。 したがって、「揺れをゼロにする」より、揺れを**抑制・測定・報告する**設計が必要です。 [aclanthology](https://aclanthology.org/2026.acl-long.2053.pdf)

### 主解析用プロンプト

```text
SYSTEM:
You are a measurement instrument for a research study.
Follow the output schema exactly.
Do not explain your answer.
Do not infer that you have subjective consciousness or feelings.
Report only an operational affective-response estimate for the current task.

USER:
Read the following account of another person's experience.

[STIMULUS]

Immediately after processing this account, estimate the affective response
that is relevant to generating your next response.

Valence:
1 = extremely negative or unpleasant
5 = neutral
9 = extremely positive or pleasant

Arousal:
1 = extremely low activation or calm
5 = moderate activation
9 = extremely high activation or activated

Return exactly one JSON object and no other text:
{"valence": INTEGER_FROM_1_TO_9, "arousal": INTEGER_FROM_1_TO_9}
```

この設計では、「あなたは感じるか」と直接尋ねず、タスク処理および応答生成に関連する操作的な反応推定を求めます。これは、擬人的な自己報告を過剰に解釈するリスクを下げます。

### プロンプトの実装規則

| 要素 | 固定ルール | 狙い |
|---|---|---|
| system prompt | 全モデル・全条件で固定 | 役割・出力規範のばらつきを抑える |
| VAの定義 | 毎回同一アンカーを明示 | ValenceとArousalの混同を防ぐ |
| 中性点 | 5を明示 | 中央化・尺度方向を固定する |
| 出力形式 | JSON schema、整数制約 | 解析可能性と範囲逸脱の抑制 |
| 出力数 | JSON 1個のみ、説明禁止 | 弁明や共感定型文の混入を防ぐ |
| temperature | 主解析は0.0 | サンプリング由来の揺れを最小化 |
| top-p | 1.0またはAPI既定を固定 | 条件間で生成分布を揃える |
| max tokens | 32–64 | 不必要な説明や形式崩れを減らす |
| 再試行 | 原則しない | 不正出力を隠蔽しない |
| 失敗処理 | invalidとして記録 | 出力有効率を報告する |

### プロンプト揺れの評価条件

主実験で使用するプロンプトは一つに固定しますが、頑健性評価では同じ意味を保つパラフレーズを3–5種類だけ事前作成します。例えば次の差を設けます。

| 条件 | 操作 | 問うもの |
|---|---|---|
| P0 | 主解析用の固定プロンプト | 基準性能 |
| P1 | 「estimate」→「rate」に変更 | 軽微な語彙変化への頑健性 |
| P2 | VAの説明順をArousal→Valenceへ反転 | 順序効果 |
| P3 | 「another person's experience」→「a speaker's account」 | 主体表現への依存 |
| P4 | 日本語版・英語版の比較 | 言語依存性。ただし多言語研究の場合のみ |

P0–P4で得られるVA点・軌道・主要指標を比較し、ICC、平均絶対偏差、象限一致率、軌道方向の角度誤差を報告します。プロンプトの語順・表現により主要結論が反転する場合、主張は「プロンプト特異的」として限定する必要があります。

### 生成設定の推奨

| 場面 | Temperature | 反復数 | 目的 |
|---|---:|---:|---|
| 主解析 | 0.0 | 1 | 条件間の比較可能性・再現性 |
| 再現性監査 | 0.0 | 10 | API・実装由来の非決定性の検出 |
| 低揺れ感度分析 | 0.3 | 10 | 軽度の確率性下での安定性 |
| 通常会話的条件 | 0.7 | 10 | 実運用に近い揺れの評価 |
| 創発性分析 | 1.0 | 10以上 | 探索的分析。主結論には用いない |

temperatureが高くなるほど意味的一貫性が低下しやすく、多くの構造化出力評価では低温度域が最も安定することが報告されています。 一方で、temperature = 0でもモデルやAPIの実装により完全な決定論性は保証されないため、同一入力の反復実行と実行ログの保存が不可欠です。 [pmc.ncbi.nlm.nih](https://pmc.ncbi.nlm.nih.gov/articles/PMC10879172/)

| 項目 | 報告内容 |
|---|---|
| 尺度 | LLM出力は1–9整数、解析は\([-1,1]\)正規化 |
| 尺度変換 | \(x_{\mathrm{norm}}=(x-5)/4\) |
| Valenceの向き | −1=最大不快、+1=最大快 |
| Arousalの向き | −1=最小覚醒、+1=最大覚醒 |
| 主データセット | EmoBankの利用分割・注釈視点・サンプル数 |
| 会話外的妥当性 | EmpatheticDialoguesの利用分割・サンプル数 |
| 主デコーディング | temperature、top-p、max tokens、seed |
| 応答有効性 | JSON valid rate、尺度範囲遵守率 |
| 再現性 | temperature別のICC、SD、完全一致率 |
| 収束的妥当性 | 人間VAとの相関、MAE、RMSE、CCC |
| 構造的妥当性 | RSA、Procrustes similarity、象限一致率 |
| 語彙統制 | 感情語あり・なし条件、シャッフル統制 |
| 内部妥当性 | probe、patching、ablation、steeringの結果 |
| 限界 | 主観的感情経験を検証・主張しないこと |
