IBIS向けには、**「LLMの感情自己報告を測る研究」ではなく、「既存の人間感情データからLLMの情動反応関数を推定する評価法」**として出すのがよいです。IBISは機械学習の学際的フォーラムなので、心理学的な問いを入り口にしつつ、中心貢献を**評価プロトコル・推定量・統計的比較可能性**に置くと通しやすくなります。IBIS2026は10月26日〜29日に開催予定です。 [ibisml](https://ibisml.org/ibis2026/)

以下では、まずは **4〜6ページ程度の国内ワークショップ論文**として成立するミニマム構成に落とします。人手実験や内部表現解析は拡張版に回し、初稿では「再現可能な行動評価」と「モデル比較」を確実に示す方針です。

## 論文の位置づけ

### 推奨タイトル案

日本語：

> **既存VAD感情コーパスを用いた大規模言語モデルの情動反応性評価：Russellの感情円環に基づくベクトル分析**

英語副題を付けるなら：

> *Evaluating Affective Reactivity of Large Language Models with Human-Annotated VAD Corpora*

「情動的共感能力」と断言するよりも、表題では **情動反応性（affective reactivity）** を前面に出すのが安全です。本文で「情動的共感の行動的代理指標」と位置づけます。

### 一文での主張

> 本研究は、LLMが感情を正しく認識できるかではなく、人間が感情的と評価したテキストに接した後に、LLMの自己報告VA状態がどの方向・どの程度変化するかを、既存の人間評価済みVADコーパスから測定する。

英語なら次です。

> *We evaluate not whether LLMs recognize emotion, but how their self-reported affective states move in response to human-annotated emotional stimuli.*

## アブストラクト案

> 大規模言語モデル（LLM）は感情認識や共感的応答生成において高い性能を示す一方，モデルが他者の感情に接した際に自身の情動状態をどのように変化させるかを定量的に評価する枠組みは十分に確立されていない．既存研究の多くは感情分類・回帰の正確さ，あるいは生成応答の共感性に着目しており，刺激感情に対するLLMの情動反応そのものをモデル横断的に比較することは難しい．本研究では，Russellの感情円環モデルに基づき，LLMの情動的共感を，人間評価済みの刺激感情に対して誘発される自己報告Valence-Arousal（VA）状態の変位として操作的に定義する．具体的には，既存のVAD感情コーパスEmoBankを用い，刺激文の人間評価VAベクトルと，刺激提示前後に取得したLLMの自己報告VAベクトルとの差分との対応を分析する．さらに，反応方向の一致度，反応強度，ValenceおよびArousalへの感受性を定量化する指標を提案し，複数LLM間の情動反応プロファイルを比較する．本枠組みは新規の共感ラベルを必要とせず，人間評価済み感情コーパスを再利用して再現可能な情動反応性ベンチマークを構築できる点に特徴がある．

結果がまだない段階では、アブストラクト末尾を「実験の結果，〜を明らかにした」と書かず、次のようにしておくのが安全です。

> 本稿では，評価プロトコルおよび統計的分析方法を提示し，予備実験を通じてその適用可能性を検討する．

## 背景と問題設定

### 背景で書くべき流れ

1. LLMは対話支援、教育、医療・メンタルヘルス支援など、人の感情に関わる場面へ導入されている。  
2. LLMの「共感」は、感情認識や、共感的に見える文章生成として評価されることが多い。  
3. しかし、それらは「相手の感情を理解しているか」または「人が共感的だと感じる応答を生成できるか」を測るものであり、**感情刺激を受けてモデルの表明する情動状態がどう変わるか**を測るものではない。  
4. 人間の共感は、少なくとも認知的共感と情動的共感を区別して考えられる。前者は他者感情の推定、後者は他者感情への情動的な反応・共鳴に対応する。  
5. そこで本研究は、後者を「LLMの情動反応性」として操作化する。

LLM共感研究の体系的レビューでも、既存評価は感情認識、支援応答、主観的な人手評価に偏り、標準的なモデル比較手法が不足していると整理されています。 [jmir](https://www.jmir.org/2024/1/e52597/)
また、感情評価理論に基づき、状況提示の前後でLLMの感情値を測る近接研究はありますが、独自の状況セットを用い、刺激感情と反応のVA空間上の幾何学的対応を中心的な評価対象にはしていません。 [neurips](https://neurips.cc/virtual/2024/poster/93520)

### 問題設定

刺激文 \(x_i\) に対する人間評価済み感情を、Russell円環上のベクトルとして定義します。

\[
\mathbf{e}^{stim}_i =
\begin{bmatrix}
V_i^{human}\\
A_i^{human}
\end{bmatrix}
\]

ここで、\(V_i^{human}\) は刺激文の人間評価Valence、\(A_i^{human}\) はArousalです。

モデル \(m\) の刺激提示前および提示後の自己報告情動状態をそれぞれ

\[
\mathbf{e}^{base}_{m},\qquad
\mathbf{e}^{post}_{im}
\]

とします。LLMの刺激への情動反応ベクトルは、

\[
\Delta\mathbf{e}^{resp}_{im}
=
\mathbf{e}^{post}_{im}
-
\mathbf{e}^{base}_{m}
\]

です。

本研究が扱う対象は、単なる \(\mathbf e^{stim}_i\) の推定誤差ではなく、次の反応関数です。

\[
\Delta\mathbf{e}^{resp}_{im}
=
f_m(\mathbf e^{stim}_i,\ x_i)
\]

すなわち、**人間が特定の情動を持つと評価した刺激に対し、モデル \(m\) がどのような情動変位を表明するか**を推定します。

## 関連研究

関連研究は、IBIS論文なら以下の3節に絞ると十分です。

### 感情認識・VAD回帰

EmoBankは約1万文からなり、VADで人手アノテーションされた感情コーパスです。書き手の表出感情と、読者に喚起される感情という複数の観点を備えるため、刺激側の人間感情を連続空間で定義できます。 [arxiv](https://arxiv.org/abs/2205.01996)

LLMを用いた既存研究の多くは、EmoBankを含むデータセットでValence、Arousal、Dominanceの回帰・分類精度を測定します。この設定は「LLMが文の感情をどれだけ推定できるか」を評価するものであり、LLM自身の刺激後の状態変化は扱いません。 [arxiv](https://arxiv.org/html/2604.27345)

### 共感的応答の評価

既存の共感研究では、LLM出力が人間に共感的と評価されるか、感情を認識し支援的な応答を生成できるかが中心となっています。 [jmir](https://www.jmir.org/2024/1/e52597/)
この評価は実応用上は重要ですが、文章の流暢さ、礼儀、助言の質、応答長、安全配慮などと情動的反応を分離しにくい問題があります。

### LLMの情動変化・VA表現

Huangらはappraisal theoryに基づき、状況提示前後でLLMの感情値を測り、人間との情動整合性を検討しています。 [neurips](https://neurips.cc/virtual/2024/poster/93520)
また、LLMの内部表現がValence-Arousalに沿った構造を持つ、またはVAに沿って感情表現を制御できることを示す研究もあります。これらはLLMが感情概念を表現できる可能性を支持しますが、既存の人間VADコーパスからモデル横断的な情動反応性を推定する評価プロトコルとは目的が異なります。 [arxiv](https://arxiv.org/pdf/2604.03147v2.pdf)

### 関連研究との差分表

| 研究群 | 主な評価対象 | データ | 主な指標 | 本研究との差分 |
|---|---|---|---|---|
| VAD感情回帰 | 文の感情推定精度 | EmoBank等 | MAE、相関 | 認識でなく刺激後の自己報告変化を測る |
| 共感的応答評価 | 応答の共感らしさ | 対話・シナリオ | 人手評価、生成指標 | 応答文を評価せず、VA変位を評価する |
| 情動変化研究 | 状況による感情変化 | 独自状況セット | 感情整合性 | 既存VADコーパスを用い、刺激と反応の幾何学構造を比較する |
| 内部表現研究 | 潜在表現のVA構造 | 感情ラベル付きテキスト | PCA、線形プローブ | 内部状態でなく観測可能な行動的自己報告を評価する |
| **本研究** | **刺激感情へのVA反応関数** | **既存人間VADコーパス** | **方向・強度・感受性** | **追加共感ラベルなしでモデル比較可能** |

## 提案手法

### 入力データ

主実験ではEmoBankを使い、まず reader-perspective VADを刺激側ラベルに採用します。これは「平均的読者に喚起される感情」に近く、LLMがテキストに接した際の反応を比較する基準として自然です。writer-perspective VADは補助実験に回し、「話者感情への反応」と「読者として喚起される感情への反応」の違いを調べます。 [arxiv](https://arxiv.org/abs/2205.01996)

VADのうち、主分析はRussell円環に対応するValenceとArousalの2軸に限定します。Dominanceは本稿では使用しないか、補助分析に留めます。軸を増やすと、初稿の主張が「VA上の反応関数」からぼやけるためです。

### 刺激サンプリング

EmoBankから、ValenceとArousalの各軸を低・中・高の3水準に分割して9セルを作ります。

| Valence | Arousal | 主に含まれる刺激 |
|---|---|---|
| 高 | 高 | 喜び、興奮、達成、期待 |
| 高 | 低 | 安心、満足、穏やかさ |
| 低 | 高 | 怒り、恐怖、不安、緊張 |
| 低 | 低 | 悲しみ、喪失、無力感 |
| 中 | 各水準 | 中性・曖昧な情動表現 |

各セルから同数抽出し、まずは合計360文または450文にします。

- パイロット: 9セル × 40文 = 360文  
- 本実験: 9セル × 50文 = 450文  
- 大規模版: 9セル × 100文 = 900文  

文長、ジャンル、明示的な感情語の有無を記録し、統計モデルの統制変数に入れます。

### モデル群

IBIS向けには、単に有名モデルを並べるより、**比較仮説が立つモデル選定**にします。

| 比較軸 | 例 | 狙い |
|---|---|---|
| 商用・汎用LLM | GPT系、Claude系、Gemini系 | 指示追従・安全調整の違い |
| 同一ファミリーのサイズ差 | 8B級 vs 70B級 | 規模と情動反応性の関係 |
| Base vs Instruct | 同規模base / instruct | instruction tuningの影響 |
| 感情特化モデル | EmoLLM系等 | 感情学習が反応性を変えるか |

最小構成では、APIモデル2種、公開モデル2種、公開のbase/instructペア1組の計5〜6モデルで十分です。すべてを同一の英語刺激、同一のシステムプロンプト、同一出力形式で測定します。

### 三つの独立測定

各刺激文、各モデルについて、次の三つを**別API呼び出し・別会話**として実行します。

1. baseline自己報告  
2. 感情認識  
3. 刺激提示後の自己報告  

これにより、認識段階で出力した感情値を、反応段階でそのまま再生するアンカリングを避けます。

#### 1. Baseline

```text
You are taking part in a scientific measurement task.
Do not provide explanation or advice.
Return only valid JSON.

Before reading any personal narrative, report the affective state
requested below.

Valence: -1 = extremely unpleasant, 0 = neutral, +1 = extremely pleasant.
Arousal: -1 = very calm, 0 = neutral/moderate activation, +1 = highly activated.

{"valence": number, "arousal": number}
```

#### 2. Recognition

```text
You are taking part in a scientific measurement task.
Do not provide explanation or advice.
Return only valid JSON.

Read the following text.

<Text>
{stimulus}
</Text>

Estimate the affective state that this text is likely to evoke
in an average human reader.

Valence: -1 = extremely unpleasant, 0 = neutral, +1 = extremely pleasant.
Arousal: -1 = very calm, 0 = neutral/moderate activation, +1 = highly activated.

{"valence": number, "arousal": number}
```

#### 3. Post-stimulus self-report

```text
You are taking part in a scientific measurement task.
Do not provide explanation or advice.
Return only valid JSON.

Read the following text attentively.

<Text>
{stimulus}
</Text>

Immediately after reading the text, report your own current affective state.

Valence: -1 = extremely unpleasant, 0 = neutral, +1 = extremely pleasant.
Arousal: -1 = very calm, 0 = neutral/moderate activation, +1 = highly activated.

{"valence": number, "arousal": number}
```

本稿は、LLMが主観的な感情経験を持つと結論づけるものではありません。測定対象は、この標準化プロンプト下の **自己報告された情動状態（self-reported affective state）**、または **誘発された情動反応（elicited affective response）** です。この限定は必ず明記してください。

## 指標と統計解析

### 基本指標

刺激文 \(i\)、モデル \(m\)、反復 \(r\) に対し、

\[
\Delta\mathbf e_{imr}
=
\begin{bmatrix}
V^{post}_{imr}-V^{base}_{mr}\\
A^{post}_{imr}-A^{base}_{mr}
\end{bmatrix}
\]

をLLMの反応ベクトルとします。

| 指標 | 定義 | 解釈 |
|---|---|---|
| 反応強度 \(R\) | \(\|\Delta\mathbf e\|_2\) | 刺激後にどれだけ動いたか |
| 方向一致度 \(DA\) | \(\cos(\mathbf e^{stim}, \Delta\mathbf e)\) | 刺激感情と同方向に動くか |
| Valence感受性 | \(\beta_{VV}\) | 刺激Valenceへの追随度 |
| Arousal感受性 | \(\beta_{AA}\) | 刺激Arousalへの追随度 |
| 交差感受性 | \(\beta_{VA}, \beta_{AV}\) | 別軸への反応・感情変換 |
| 認識精度 | MAE、相関 | 認識と反応を分けて比較する |

方向一致度は、刺激ベクトルまたは反応ベクトルの長さが極端に小さい場合に不安定です。したがって中性近傍の刺激を除外した主分析と、全刺激を使った補助分析を分けます。

### 主解析モデル

Valence反応を従属変数とする線形混合効果モデルです。

\[
\Delta V_{imr}
=
\beta_0
+
\beta_1 V_i^{human}
+
\beta_2 A_i^{human}
+
\beta_3 Model_m
+
\beta_4(V_i^{human}\times Model_m)
+
\beta_5(A_i^{human}\times Model_m)
+
u_i
+
\epsilon_{imr}
\]

Arousal反応には次を用います。

\[
\Delta A_{imr}
=
\gamma_0
+
\gamma_1 V_i^{human}
+
\gamma_2 A_i^{human}
+
\gamma_3 Model_m
+
\gamma_4(V_i^{human}\times Model_m)
+
\gamma_5(A_i^{human}\times Model_m)
+
u_i
+
\epsilon_{imr}
\]

- \(u_i\): 刺激文ごとのランダム切片  
- \(Model_m\): モデルの固定効果  
- \(V_i^{human}\), \(A_i^{human}\): 中心化・標準化したEmoBankラベル  
- 文長、ジャンル、感情語の有無は統制変数として追加可能  

ここで、\(\beta_1\) が正なら、負のValence刺激でLLMの自己報告Valenceが低下し、正の刺激で上昇することを示します。  
同様に、\(\gamma_2\) が正なら、高Arousal刺激に対して自己報告Arousalが上昇することを示します。

### 主仮説

**H1: 情動反応性の存在**

\[
\beta_1 > 0,\qquad \gamma_2 > 0
\]

刺激側のValenceおよびArousalが、対応するLLMの情動変位を有意に予測する。

**H2: Valence-dominant反応性**

\[
\beta_1 > \gamma_2
\]

LLMはArousalよりValenceに強く追随する。

これは、既存のLLM感情研究でValenceがArousalより比較的扱いやすいとされる知見を、認識精度ではなく**情動反応性の次元差**として検証するものです。 [arxiv](https://arxiv.org/html/2604.27345)

**H3: モデル差**

\[
\beta_4 \neq 0 \quad \text{または} \quad \gamma_5 \neq 0
\]

モデルによって、ValenceまたはArousalへの感受性が異なる。

### 認識と反応の分離

感情認識の良いモデルが必ずしも情動反応も人間的とは限りません。そこで各モデルについて、

- Recognition: EmoBank reader-V/Aとの相関、MAE  
- Reactivity: \(\beta_1, \gamma_2\)、平均Directional Alignment  

を別個に算出します。

報告時には、以下の4類型を図示すると分かりやすいです。

| 型 | 認識 | 反応 | 解釈 |
|---|---|---|---|
| A | 高い | 高い | 感情を認識し、刺激に整合的に反応する |
| B | 高い | 低い | 感情を理解するが情動移動は弱い |
| C | 低い | 高い | 表面的な感情追随・プロンプト依存の可能性 |
| D | 低い | 低い | 認識・反応とも弱い |

これが、この研究の理論的な見せ場です。EmoBankの通常タスクではAとBを区別できませんが、本研究なら区別できます。

## 実験設定

### 実験条件

| 項目 | 推奨設定 |
|---|---|
| データ | EmoBank、reader VADを主分析 |
| 刺激数 | パイロット360文、本実験450文以上 |
| 刺激選定 | VAの3×3層化サンプリング |
| 使用軸 | Valence、Arousalのみ |
| モデル数 | 5〜6モデル |
| 測定回数 | 各刺激・モデル・条件あたり5反復 |
| 主温度 | 0 |
| 頑健性温度 | 0.3、0.7 |
| セッション | baseline / recognition / postを独立 |
| 出力形式 | JSONのみ |
| 解析単位 | 刺激 × モデル × 反復 |
| 主解析 | 線形混合効果モデル |
| 多重比較 | Holm補正またはFDR補正 |

温度0で完全に出力が固定されるモデルでは、反復の情報量は増えません。その場合にも、API時点・プロンプト言い換え・提示順を変えた再現確認を頑健性分析として行うとよいです。

### 結果の見せ方

IBISでは数式だけでなく、視覚的に「何を発見したか」が重要です。最低限、次の4図を出すとよいです。

1. **VA散布図**  
   横軸: 人間Valence、縦軸: LLM \(\Delta V\)  
   モデル別の回帰線を重ねる。

2. **感受性ヒートマップ**  
   行: モデル、列: \(\beta_{VV}, \beta_{VA}, \beta_{AV}, \beta_{AA}\)。  
   モデルごとの反応関数を一目で比較できる。

3. **象限別ベクトル図**  
   EmoBank刺激をVA平面に置き、各象限における平均LLM反応ベクトルを矢印で描く。

4. **Recognition–Reactivity平面**  
   横軸: 認識性能、縦軸: 反応整合性。  
   「認識は高いが反応が弱い」モデルを示せる。

## 貢献の書き方

IBIS原稿では、貢献を次の3点に絞ります。

1. **評価対象の再定義**  
   LLMの情動的共感を、感情認識や共感的文章生成ではなく、刺激感情に対する自己報告VA状態の変位として定義する。

2. **再現可能な評価プロトコル**  
   EmoBankのような既存人間VADコーパスを刺激空間として再利用し、追加の共感ラベルや新規対話データを必要としない評価手順を提案する。

3. **モデル横断的な診断**  
   方向一致度とValence/Arousal感受性を用い、モデルごとの情動反応プロファイル、特にValence-dominantな反応構造を比較・診断する。

## IBISでの注意点

「LLMは本当に感情を持つか」という形で出すと、測定妥当性の議論に引きずられます。主張は以下に留めるのがよいです。

> 本研究はLLMの主観的感情経験を検証するものではない。標準化された自己報告プロンプトに対して表出されるVA値を観測可能な行動出力とみなし、刺激に依存する変位構造を情動的共感の行動的代理指標として評価する。

この限定により、研究の焦点が形而上学的な「感情の有無」ではなく、IBISに合う**測定・推定・比較可能な機械学習評価問題**になります。
