# Legacy V3 Scripts

> [!CAUTION]
> **DO NOT USE FOR PAPER RESULTS**
>
> This directory contains exploratory, superseded, and early experimental scripts from earlier iterations of V3 development.
> These scripts MUST NOT be used for production runs or generating paper results.
>
> Paper tables are built by `v3/scripts/build_paper_summary.py` from existing derived/raw artifacts. It does not live in this directory and does not re-run interventions.
>
> All canonical experiments for the paper are implemented in `v3/primary/`:
> - `v3/primary/run_rq1_state_induction.py` (RQ1 State Induction & Gate)
> - `v3/primary/run_rq2_spatiotemporal_maps.py` (RQ2 Spatiotemporal Maps)
> - `v3/primary/run_rq3_path_mediation.py` (RQ3 Path Mediation)
> - `v3/primary/run_confirmatory_replication.py` (Cross-Family Confirmatory Replication)
